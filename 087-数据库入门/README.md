# 数据库入门

来源：[数据库入门](https://apxml.com/zh/courses/introduction-to-databases)

了解数据库和数据管理系统的基本知识。本课程涵盖核心知识点，关系型 (SQL) 数据库与 NoSQL 数据库的区别，以及如何使用基本的 SQL 命令与数据进行操作。掌握有效存储、组织和获取信息的必要准则。适合数据管理初学者。

预计学时：8 小时

先修要求：无需预备知识

## 学习目标

- **核心数据库知识**：阐述什么是数据库和数据库管理系统 (DBMS)，以及它们的使用原因。
- **关系型模型基础**：描述关系型模型的基本构成部分，包括表、行、列和主键。
- **基本 SQL 查询**：编写简单的 SQL 语句，以获取 (SELECT)、插入 (INSERT)、修改 (UPDATE) 和删除 (DELETE) 数据。
- **NoSQL 数据库认知**：识别不同类型 NoSQL 数据库的存在及其一般用途。
- **数据管理准则**：理解组织和管理数据的基本准则。
