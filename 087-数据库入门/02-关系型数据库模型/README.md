# 第 2 章：关系型数据库模型

来源：[原章节](https://apxml.com/zh/courses/introduction-to-databases/chapter-2-relational-database-model)

[返回课程目录](../README.md)

在明确了数据库和数据库管理系统（DBMS）的用途之后，我们将着重介绍一种最常用的数据组织方式：关系模型。这种方式提供了一种结构化且逻辑性的方法，能有效地存储和管理信息。

本章中，你将学习关系型数据库的基本构成要素。我们将讲解数据如何使用列（属性）和行（记录）在表中构成。你将理解数据类型的重要性，主键在确保唯一性方面的作用，以及外键如何用于建立不同表之间的关联。我们还将简要介绍规范化，将其作为设计高效数据库的一种方法。
