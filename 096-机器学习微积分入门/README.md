## 学习目标

- **函数要点**：领会函数及其表示方法，并知晓极限作为微积分的基点。
- **导数**：计算简单函数的导数，并理解其作为变化率的含义。
- **优化入门**：了解导数如何用于寻找函数的最小值或最大值，这是模型优化的主要思路。
- **梯度下降直观理解**：理解梯度下降的要点，以及它在训练机器学习模型中的用途。
- **偏导数**：学习如何计算多输入函数的偏导数，并知晓梯度向量。
