## 学习目标

- **合成数据生成方法**：理解并实行多种生成适合大语言模型的合成文本数据的方法。
- **合成数据应用于LLM预训练**：使用合成数据集以增加并改进大语言模型的预训练阶段。
- **合成数据应用于LLM微调**：使用合成数据有效微调LLM以适应特定任务和行为，包含遵循指令。
- **合成数据质量评估**：培养评估生成合成数据质量、多样性及用途的能力。
- **实践操作**：获得制造合成数据生成流程及其在大语言模型工作流中使用的实践经验。
