# 第 4 章：认识不同的大语言模型

来源：[原章节](https://apxml.com/zh/courses/intro-large-language-models/chapter-4-different-llm-types)

[返回课程目录](../README.md)

之前的章节介绍了大语言模型的核心原理、简易运作方式以及基本提示技巧。本章将介绍大语言模型中的各种类型。

本章概述了不同类型的大语言模型。您将了解到：
*   什么是奠基模型。
*   通用模型与专用于特定任务模型之间的区别。
*   开放式模型与封闭式专有模型之间的不同之处。
*   模型大小通常如何与性能相关联。
*   与模型交互的常见方式，重点是应用程序编程接口（API）和基于网页的界面。
