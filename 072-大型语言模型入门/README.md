## 学习目标

- **LLM基本知识**：定义大型语言模型，并阐述它们与AI和NLP的关系。
- **主要运作方式**：描述LLM如何处理文本并在高层次上生成回复。
- **提示词入门**：理解提示词的原理，以及如何为LLM编写简单指令。
- **模型互动**：使用网页界面或简单API调用与预训练LLM进行互动。
- **模型种类**：识别不同类型的LLM及其一般特征。
