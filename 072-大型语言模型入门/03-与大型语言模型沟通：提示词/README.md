# 第 3 章：与大型语言模型沟通：提示词

来源：[原章节](https://apxml.com/zh/courses/intro-large-language-models/chapter-3-communicating-with-llms-prompts)

[返回课程目录](../README.md)

你已经了解了大型语言模型是什么，并对其运作方式有了大致的认识。下一步是学习如何与它们进行有效的交流。大型语言模型本身并不知道你需要它们做什么；你需要提供指令。

本章主要讲解**提示词**——你为引导大型语言模型输出而提供的输入内容。你将学到：

*   在大型语言模型中，提示词是由什么组成的。
*   编写清晰有效提示词的基本方法。
*   如何组织指令并提供示例（少样本提示）以提升输出效果。
*   调节模型回应长度和格式的方法。
*   在使用提示词时常遇到的问题以及如何应对。

完成本章学习后，你将掌握提示词的基本原理，并能够开始制定简单的指令来与大型语言模型沟通。
