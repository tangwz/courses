# 通过网页界面交互

来源：[原文](https://apxml.com/zh/courses/intro-large-language-models/chapter-5-using-pre-trained-llms/interacting-via-web-interfaces)

[返回章节目录](README.md) · [返回课程目录](../README.md)

通过网页界面与预训练 (pre-training)大型语言模型进行交互，是最直接的上手方式。许多开发或托管大型语言模型的机构都提供简单的网站或网页应用，让任何人都能在浏览器中直接输入提示并获得回应。这种方法不需要编程知识，是试用LLM功能的一个很好的起点。

可以将这些网页界面视为LLM的交互式试验场。它们提供了图形用户界面（GUI），隐藏了模型服务的内部复杂情况。您很可能在线上已经遇到过聊天机器人或AI助手形式的类似界面。

### LLM网页界面的常见功能

虽然设计各不相同，但大多数用于与LLM交互的网页界面都有一些共同组成部分：

1. **提示输入区：** 这通常是一个文本框，您可以在其中输入对LLM的指令或问题。这是您向模型传达意图的主要方式。
2. **提交/生成按钮：** 在编写好提示后，您会点击一个按钮（通常标有“提交”、“生成”、“发送”或类似字样），将您的输入发送给模型。
3. **回应显示区：** 该部分显示LLM根据您的提示生成文本。有时文本会一次性出现，而其他界面可能会逐字或逐句显示，模拟对话。
4. **对话历史（常见）：** 许多界面，特别是以聊天为中心的界面，会保留您当前交互的记录，显示您的提示和模型的回答。这有助于模型在一次会话中保持上下文 (context)。
5. **可选控制项：** 某些界面可能会提供基本控制项来调整模型表现，尽管这在最简单的实现中不太常见。您偶尔可能会看到以下选项：
   - 选择特定模型版本（如果提供商提供多个）。
   - 清除对话历史以重新开始。
   - 修改简单参数 (parameter)（尽管详细的参数设置通常保留给API交互，我们稍后会讨论）。

### 交互过程

使用网页界面的过程设计得直观易懂：

1. **您提供输入：** 在指定的文本框中输入您想要的提示。
2. **您发送提示：** 点击提交按钮。
3. **界面通信：** 网页应用通过互联网将您的文本提示发送到托管预训练 (pre-training)LLM的服务器。
4. **LLM处理：** 模型根据其训练数据和内部算法处理您的提示。
5. **LLM生成：** 模型产生文本回应。
6. **界面显示：** 网页应用从服务器接收生成的文本，并将其显示回您的回应区。

整个循环通常在几秒钟内完成，提供了近乎实时的交互体验。

### 简单演示

让我们想象一下使用一个通用LLM网页界面：

1. **打开界面：** 您使用网页浏览器访问LLM服务提供的网站。
2. **找到输入框：** 您会看到一个醒目区域，可能标有“在此输入您的提示”之类的字样。
3. **输入提示：** 您输入：`用三个简单步骤解释水循环。`
4. **提交：** 您点击输入框旁边的“生成”按钮。
5. **查看回应：** 短暂暂停后，文本出现在回应区，可能显示如下：
   - `1. 水从海洋和湖泊蒸发到空气中。`
   - `2. 这些水蒸气形成云。`
   - `3. 水以雨或雪的形式落回地球。`
6. **尝试另一个提示：** 您可以清除输入（或者在聊天界面中在前一次交互下方直接输入），然后尝试不同的内容，例如：`写一首关于猫的简短快乐诗歌。` 界面会发送这个新提示，LLM会生成相应的诗歌。

### 网页界面的优点

使用网页界面对初学者尤其有利：

- **易用性：** 无需设置或编码。只要您会使用网站，就能使用这些界面。
- **简洁性：** 它们提供了一种直接、不复杂的方式来查看LLM能做什么。
- **快速试验：** 您可以快速测试不同的提示和变体，以了解模型如何回应。
- **即时反馈：** 您的提示结果直接显示，使因果关系清晰明了。

### 需注意的限制

虽然非常适合初次使用，但网页界面也有其限制：

- **控制有限：** 您通常对模型参数 (parameter)（如创意度与事实准确性）或输出格式的影响很小。
- **手动操作：** 交互是手动的。您无法轻松自动化任务，或将LLM的功能整合到您自己的软件或工作流程中。
- **使用限制：** 通过网页界面提供的免费访问通常对每天可发送的提示数量或可生成的文本量设有上限。

网页界面为预训练 (pre-training)LLM的功能提供了一个有益的实践入门。它们让您可以自由尝试，并对提示如何影响模型输出建立认识。一旦您熟悉了基本交互，您可能希望获得更多控制，或者能够将LLM的能力整合到应用程序中。这时，我们下一节的主题——应用程序编程接口（API）——就显得有用了。
