# 第 5 章：使用预训练大语言模型

来源：[原章节](https://apxml.com/zh/courses/intro-large-language-models/chapter-5-using-pre-trained-llms)

[返回课程目录](../README.md)

在掌握了大语言模型的基本原理和运作方式之后，本章的重点将转向具体运用。本章将指导您如何与已在规模化数据集上训练好的模型进行交互。

您将首先了解什么是“预训练”模型，以及为什么使用预训练模型通常是开始发挥大语言模型功能最直接的方式。接着，我们将介绍查找和选择合适的LLM服务或平台的方法。实践部分将演示如何通过常用网页界面进行操作，并提供使用应用程序编程接口（API）进行编程访问的基础说明。这包括如何构建简单的API请求以及理解模型生成的响应。本章最后会安排一个围绕简单文本生成任务的实践练习。
