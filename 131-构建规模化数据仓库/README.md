# 构建规模化数据仓库

来源：[构建规模化数据仓库](https://apxml.com/zh/courses/building-scalable-data-warehouses)

本课程解析现代数据仓库的高级架构模式，侧重于Snowflake、BigQuery和Redshift等大规模并行处理 (MPP) 系统。内容讲解高吞吐量 (throughput)数据摄取、包含Data Vault在内的复杂建模方法，以及分布式系统的查询性能调优。您将实现数据分区、实体化视图和自动化治理等方案。课程内容重视技术实施和架构决策，旨在帮助工程师应对TB级以上数据集的数据平台扩展。

预计学时：15 小时

先修要求：SQL与数据仓库经验

## 学习目标

- **架构设计**：设计采用计算与存储分离原则的分布式存储系统。
- **性能调优**：通过剪枝、聚类和实体化视图优化查询执行计划。
- **高级建模**：实现Data Vault和维度建模策略，以适应演进模式。
- **数据治理**：自动化基于角色的访问控制和行级安全策略。
