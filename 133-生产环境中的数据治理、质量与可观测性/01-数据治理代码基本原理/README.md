# 第 1 章：数据治理代码基本原理

来源：[原章节](https://apxml.com/zh/courses/data-governance-quality-observability-production/chapter-1-foundations-data-governance-code)

[返回课程目录](../README.md)

治理常被视为一项通过文件和会议进行管理的行政职能。然而，在生产工程环境中，它以技术规程的形式运行。有效的数据管理需要从人工执行转向自动化系统，其中策略以代码形式存在。

本章确立了管理数据访问、所有权和安全性所需的工程规约。我们将使用技术术语界定治理要求，并审视程序化分类数据资产的方法。您将学习如何直接在您的基础设施配置中实施基于角色的访问控制 (RBAC) 模型。此外，本课程涉及策略即代码架构，使您能够编写在代码合并前强制执行合规规则的测试。在本模块结束时，您将能够使用Python应用访问策略，并确保治理逻辑在您的数据系统中可靠运行。
