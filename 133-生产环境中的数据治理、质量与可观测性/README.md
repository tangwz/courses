# 生产环境中的数据治理、质量与可观测性

来源：[生产环境中的数据治理、质量与可观测性](https://apxml.com/zh/courses/data-governance-quality-observability-production)

本课程为在生产环境维护可靠的数据系统构建技术架构。课程侧重于数据工程与可靠性的结合处，即数据可靠性工程。您将学习实现自动化质量检查，为数据管道配置可观测性，并通过代码管理数据治理。

本课程从理论转向实践应用，侧重于测试框架、异常检测算法和元数据规范的实际应用。我们考察如何通过避免架构偏移、发现数据时效问题以及在部署管道内执行策略来维护数据资产的信任度。本内容面向需要将数据质量投入实际运作、并确保其架构能承受规模化组织需求的工程师。

预计学时：10 小时

先修要求：Python编程和数据管道知识

## 学习目标

- **数据质量测试**：编写并部署自动化断言，以验证数据的准确性、完整性和一致性。
- **可观测性实现**：构建监控系统，实时追踪时效性、数据量和架构变化。
- **程序化治理**：实现策略即代码和基于角色的访问控制，管理数据安全和合规性。
- **数据血缘**：追踪数据依赖关系和影响分析，采用OpenLineage等行业规范。
