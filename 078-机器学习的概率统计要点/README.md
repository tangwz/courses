## 学习目标

- **核心原理**：理解概率统计在机器学习应用中的作用。
- **描述性统计**：计算和解释数据集的集中趋势和离散程度指标。
- **数据可视化**：制作和理解直方图、箱线图等基本数据图形。
- **概率要点**：运用基本概率法则，并理解条件概率。
- **概率分布**：识别和理解常见的离散和连续概率分布。
- **统计推断概论**：掌握统计推断、置信区间和假设检验的基本思路。
- **Python实践**：使用NumPy和Pandas等Python库进行基本统计计算和数据分析。
