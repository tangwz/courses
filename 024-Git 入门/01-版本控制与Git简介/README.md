# 第 1 章：版本控制与Git简介

来源：[原章节](https://apxml.com/zh/courses/getting-started-with-git/chapter-1-intro-version-control-git)

[返回课程目录](../README.md)

本章为理解和使用 Git 做了准备。我们首先解释版本控制的理念，以及它为何是管理项目（特别是软件开发）不可或缺的工具。你将了解到不同类型的版本控制系统，并理解 Git 分布式特性的优点。

学完本章后，你将能够：

*   定义版本控制及其优点。
*   区分集中式和分布式版本控制系统。
*   认识 Git 中的主要组成部分，如仓库、提交和分支。
*   在 Windows、macOS 或 Linux 上安装 Git。
*   完成 Git 用户身份的初始配置。
*   使用 Git 的帮助功能查找命令信息。
