# 第 2 章：你的第一个 Git 仓库

来源：[原章节](https://apxml.com/zh/courses/getting-started-with-git/chapter-2-first-git-repository)

[返回课程目录](../README.md)

Git 安装并配置好后，你就可以通过创建你的第一个仓库来动手使用它了。本章将介绍一些用于管理本地项目的基本命令。

你将学会如何：
*   初始化一个新仓库，使用 `git init` 命令。
*   理解核心工作流程：文件修改、暂存和提交状态之间的区别。
*   暂存更改，以便将其包含在下一个快照中，使用 `git add` 命令。
*   保存项目状态的快照，使用 `git commit` 命令，包括如何编写有用的提交信息。
*   检查文件和仓库的状态，使用 `git status` 命令。
*   查看项目的历史记录，使用 `git log` 命令。
*   配置 Git 忽略特定文件或目录，使用 `.gitignore` 文件。

学完本章，你将能够创建一个简单的 Git 仓库，跟踪文件的改动，并查看这些改动的历史记录。
