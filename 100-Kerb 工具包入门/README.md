# Kerb 工具包入门

来源：[Kerb 工具包入门](https://apxml.com/zh/courses/getting-started-with-llm-toolkit)

本课程面向开发者，教授如何使用 Kerb Python LLM 工具包构建应用程序。您将学习如何实现文本生成、检索增强生成 (RAG) 系统、自主代理等。通过 Kerb 完善的模块集，您将掌握提示词管理、数据处理、性能优化以及应用程序安全保障的技能。

预计学时：12 小时

先修要求：中级 Python 编程技能

## 学习目标

- **LLM 生成**：通过统一接口，使用多个 LLM 服务提供商生成文本。
- **提示词工程**：使用模板、版本管理和少样本示例，构建有效提示词。
- **RAG 系统**：从零开始构建和优化检索增强生成 (RAG) 系统。
- **自主代理**：开发能够使用工具执行复杂任务的自主代理。
- **应用程序优化**：在 LLM 应用程序中实现缓存、内存和安全功能。
- **数据处理**：处理和准备各类文档，供 LLM 应用程序使用。
