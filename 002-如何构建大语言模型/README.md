# 如何构建大语言模型

来源：[如何构建大语言模型](https://apxml.com/zh/courses/how-to-build-a-large-language-model)

本课程为工程师提供了构建、训练和优化大语言模型 (LLM)的全面指南。内容涵盖主要组成部分，从数据准备和基于Transformer的架构设计，到高级分布式训练方法和高效部署策略。掌握开发复杂语言模型所需的实用知识。

预计学时：80 小时

先修要求：编程与深度学习

## 学习目标

- **大语言模型架构设计**：实现并定制用于大规模语言建模的基于Transformer的架构。
- **大语言模型数据管理**：建立用于获取、清洗和管理适用于大语言模型预训练的海量文本数据集的流程。
- **分布式训练实现**：配置并运行使用各种并行策略和框架的大语言模型分布式训练任务。
- **模型训练与优化**：应用高级优化技术、学习率调度和专用于大语言模型训练的正则化方法。
- **大语言模型评估技术**：使用内部指标和下游任务基准评估模型性能。
- **推理优化**：实现模型压缩和高效推理服务的方法。
