# 第 1 章：数据科学入门

来源：[原章节](https://apxml.com/zh/courses/introduction-to-data-science/chapter-1-getting-started-with-data-science)

[返回课程目录](../README.md)

本章将介绍数据科学领域。我们将从定义数据科学是什么开始，并讨论其在当今数据驱动环境中的重要性。

您将了解：
*   数据科学的核心理念及其主要目标。
*   数据科学在不同行业中的实际应用价值。
*   数据科学家角色的典型职责。
*   该领域所需基础技能的概览。
*   数据科学任务中常用软件和语言的简要介绍。

学完本章，您将更清楚地了解数据科学的构成以及所涉及的基础要素。
