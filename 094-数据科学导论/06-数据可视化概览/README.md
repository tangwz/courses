# 第 6 章：数据可视化概览

来源：[原章节](https://apxml.com/zh/courses/introduction-to-data-science/chapter-6-introduction-data-visualization)

[返回课程目录](../README.md)

在完成数据准备和初步分析后，以视觉方式呈现数据对于梳理并传递信息变得不可或缺。本章着重介绍数据可视化的基础知识。

我们将介绍创建数据可视化形式的目的，并考察常用的图表类型，包括柱状图、折线图、饼图和散点图。你将学会选择合适图表的标准，以匹配你的数据和要传递的信息。我们还将审视有助于制作出有效且清晰的可视化图表的重要原则，确保你的图表能准确传达信息。此外，还将简要介绍用于数据可视化的常用软件和库。学完本章，你将明白如何运用基础视觉元素进行数据查看并传达结果。
