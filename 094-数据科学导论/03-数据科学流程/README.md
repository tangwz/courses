# 第 3 章：数据科学流程

来源：[原章节](https://apxml.com/zh/courses/introduction-to-data-science/chapter-3-data-science-process)

[返回课程目录](../README.md)

在了解了数据科学是什么以及数据自身的特性之后，我们现在来看数据科学项目通常是如何进行的。类似于软件开发，数据科学也遵循一个普遍的工作流程，即一系列通常需要迭代的步骤，以从最初的问题过渡到最终的见解或产品。

本章将介绍数据科学流程的常见阶段。你将学到：

*   典型数据科学工作流程的整体结构。
*   明确定义你要解决的问题的重要性。
*   获取数据的不同方法（数据采集）。
*   数据准备工作的必要性概览。
*   初始数据分析（EDA）的目的。
*   建模基本思路的初步介绍。
*   传达分析结果的重要性。

了解这个流程为系统地处理数据相关任务提供了一个框架。
