# 数据科学导论

来源：[数据科学导论](https://apxml.com/zh/courses/introduction-to-data-science)

本课程提供数据科学理念与方法的入门知识。学员将学习基本要点、数据处理方式、基础分析方法以及结果呈现技巧。本课程专为有意进入数据驱动方向或人工智能工程的人士设计。

预计学时：12 小时

先修要求：无需预备知识。

## 学习目标

- **核心要点**：解释数据科学定义、主要组成部分与典型工作流程。
- **数据种类**：辨识并区分不同种类的数据（结构化、非结构化、定性、定量）。
- **数据处理**：理解数据收集方法以及数据准备的必要性。
- **基础分析**：使用汇总统计量进行简单的数据预处理分析。
- **数据可视化**：识别常用图表类型并理解有效数据呈现的规则。
- **术语**：熟悉常见数据科学术语与工具。
