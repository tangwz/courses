# Keras深度学习要领

来源：[Keras深度学习要领](https://apxml.com/zh/courses/deep-learning-fundamentals-keras)

使用Keras API，为深度学习奠定扎实功底。本课程将指导您掌握神经网络基本原理、实用实现方法，并构建用于常见人工智能任务的CNN和RNN等常用模型。学习如何通过Python和Keras，有效地训练、评估并优化您的深度学习模型。

预计学时：24 小时

先修要求：Python，机器学习基本原理

## 学习目标

- **神经网络原理**：理解人工神经网络的结构与功能，包括层、激活函数和权重。
- **Keras API熟练运用**：熟练运用Keras API（顺序式和函数式）来定义、构建和编译深度学习模型。
- **模型训练流程**：掌握深度学习模型训练的机制，包括损失函数、优化算法和反向传播。
- **卷积神经网络 (CNN)**：使用Keras实现CNN用于图像识别任务，理解卷积层和池化层。
- **循环神经网络 (RNN)**：使用Keras实现RNN和LSTM用于序列数据处理任务，例如文本分析。
