# 第 1 章：深度学习知识概览

来源：[原章节](https://apxml.com/zh/courses/deep-learning-fundamentals-keras/chapter-1-intro-deep-learning-concepts)

[返回课程目录](../README.md)

本章提供使用深度学习和Keras所需的必要背景知识。我们首先定义深度学习，并阐述它与机器学习和人工智能的关系。您将了解基本计算单元——人工神经元，以及神经元如何分层排列以形成网络结构。我们还将讨论这些网络如何使用监督学习方法从数据中学习模式。

本章接着介绍Keras，这是贯穿本课程用于构建和训练模型的高层API。我们将了解它的特性以及与TensorFlow的结合。最后，我们将讲解设置Python环境以使用TensorFlow和Keras所需的实际步骤，并以一个简单检查来确认所有组件都已正确安装。

在本章结束时，您将理解深度学习基本术语、基本神经网络的结构，并拥有一个即用型Keras环境，用于构建您的第一个模型。
