# 生产环境中RAG系统的优化

来源：[生产环境中RAG系统的优化](https://apxml.com/zh/courses/optimizing-rag-for-production)

本课程提供优化检索增强生成（RAG）系统的高级方法，适用于生产部署。内容涵盖提升检索准确性、生成质量、系统性能和成本效益的详细策略。学员将学习如何应对RAG方案扩展时遇到的复杂问题，以及如何长期保持其有效性。本课程材料侧重于实践操作和高级问题解决，以适应具体应用。

预计学时：36 小时

先修要求：RAG基础，Python编程，机器学习。

## 学习目标

- **高级检索优化**：应用精细方法，提高RAG管道中信息检索的准确性和相关性。
- **生成微调与控制**：运用高级方法微调生成器模型，并控制生产RAG系统中的输出质量。
- **RAG性能工程**：分析并优化规模化RAG系统的延迟、吞吐量和资源利用率。
- **成本管理策略**：制定并执行策略，管理和降低生产RAG系统的运营成本。
- **高级评估与监控**：设计并实施生产环境中RAG系统的全面评估框架和监控方案。
- **可扩展性与可靠性架构**：构建RAG系统，以实现在高要求生产环境中的高可用性、容错性和可扩展性。
