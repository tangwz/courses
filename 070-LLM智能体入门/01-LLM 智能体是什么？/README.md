# 第 1 章：LLM 智能体是什么？

来源：[原章节](https://apxml.com/zh/courses/intro-llm-agents/chapter-1-what-are-llm-agents)

[返回课程目录](../README.md)

本章将建立对LLM智能体的基本认识。它首先讲述大型语言模型（LLM）从文本生成器到作为能执行动作的系统核心的演变过程。本部分内容会说明智能体如何克服简单聊天机器人的局限，并对LLM智能体给出准确的定义。

本章接着考察这些智能体的用途，说明它们为何有用，以及它们与传统自动化脚本有何不同。通过示例应用来展现它们的实际能力。此外，本章会介绍智能体的自主性，并解释这些系统如何在一定程度上自主运作。

完成本章学习后，您将能够：
*   阐释LLM如何用于构建能进行智能动作的系统。
*   定义LLM智能体，并区分它与简单的LLM应用。
*   阐述使用LLM智能体的主要目的和益处。
*   比较LLM智能体与传统自动化方法。
*   识别LLM智能体能完成的任务示例。
*   掌握智能体自主运作的基本思路。
