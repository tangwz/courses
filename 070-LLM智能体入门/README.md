## 学习目标

- **LLM智能体基本原理**：理解LLM智能体是什么、其用途，以及与普通LLM的区别。
- **智能体架构**：辨识LLM智能体的核心构成部分，包括LLM、工具、记忆和规划机制。
- **基础智能体创建**：开发能执行预设任务的简单LLM智能体。
- **工具使用**：学习智能体如何与外部工具及API交互以扩展其能力。
- **简单规划**：掌握智能体如何规划并执行一系列行动的基本方法。
