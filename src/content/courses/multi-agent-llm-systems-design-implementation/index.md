本课程全面介绍如何设计与实现基于大型语言模型（LLM）的多智能体系统。学员将学习先进的架构模式、智能体间通信策略、复杂工作流程编排以及有效的评估方法。通过实践指导与动手操作环节，您将掌握构建与管理精巧人工智能智能体团队的技能，使之能够协作解决问题和执行任务。本课程面向希望使用大型语言模型构建具备多个交互智能体的高级应用的工程师和开发人员。
