本章介绍大型语言模型（LLM）及其规模。我们将首先定义什么是大型语言模型，以及它在处理和生成人类语言方面的基本作用。

您将了解这些模型的核心构成要素：参数。我们将解释参数代表什么，以及它们为什么是衡量大型语言模型规模的标准指标。这包括理解常用的单位，例如数十亿参数（$B$）。最后，我们将查看不同大型语言模型的例子，以帮助您理解可能会遇到的各种模型规模。
