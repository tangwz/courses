本章为 Julia 的使用提供初步步骤。您将学习 Julia 语言本身、其设计目标，以及它在技术计算、数据科学和人工智能等方面的应用。我们将讲解安装过程、配置开发环境，并介绍 Julia REPL 以进行交互式操作。您也将获得编写和运行第一个 Julia 脚本的指导。此外，我们将讨论核心语法元素，以及获取文档和支持的途径。到本章结束时，您将拥有一个可用的 Julia 环境，并对如何开始编程有初步的认识。
