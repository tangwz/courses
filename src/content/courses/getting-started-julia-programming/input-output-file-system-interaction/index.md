应用程序常常需要与用户通信或持久化管理数据。本章介绍 Julia 在输入输出 (I/O) 操作方面的功能。您将学习如何在控制台显示信息、接受用户输入以及操作文件系统。主要内容包括从文件读取和写入文件，以及管理文件路径，让您的程序能处理超出其当前运行范围的数据。
