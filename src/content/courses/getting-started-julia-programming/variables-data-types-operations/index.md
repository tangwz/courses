程序的基本运行离不开数据。在设置好Julia环境并运行了第一个脚本之后，本章将重点介绍Julia如何管理这些数据。我们将介绍用于存储数据的变量，并了解Julia内置的数据类型。

你将学到：

*   定义变量并为其赋值。
*   使用常见的数据类型，包括数字（如整数和浮点数）、布尔值（真或假）和字符串（文本）。
*   使用这些类型执行基本操作。
*   选择性地为变量指定数据类型，以提高代码清晰度。
*   在需要时将数据从一种类型转换为另一种类型。
*   使用常量来表示不应改变的值。

这些内容为构建更复杂的程序提供了准备。
