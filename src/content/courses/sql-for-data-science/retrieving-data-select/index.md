在上一章理解了关系型数据库结构后，我们现在将重点放在数据提取上。`SELECT` 语句是查询表中信息的主要工具。

本章介绍 `SELECT` 的主要语法和用法。您将学习如何：

*   从表中选定特定列。
*   选择所有可用列。
*   使用别名来为查询结果中的列提供临时的、易读的名称。
*   使用 `LIMIT` 子句（或其数据库特有的等效项）来控制返回的行数。

各节中都包含实践练习，帮助您运用这些方法。
