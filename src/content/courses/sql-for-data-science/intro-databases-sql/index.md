数据常见于或存储在关系数据库系统中。了解这些系统如何组织信息，是数据科学中有效获取和分析数据的前提。本章将为此铺垫。

我们将介绍关系数据库的结构，包括表、列、行和基本数据类型。随后，我们会介绍结构化查询语言 (SQL)，它是与这些数据库交流的主要工具。学完本章后，您将了解基本术语以及 SQL 在数据访问方面的作用。本章也包含关于搭建练习环境的可选指导。
