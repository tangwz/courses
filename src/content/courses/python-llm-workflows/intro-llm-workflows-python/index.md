本章旨在帮助您理解如何使用 Python 将大型语言模型（LLM）集成到可用的程序中。我们首先定义 LLM 工作流的构成，并考察构成 LLM 驱动软件的常见组成部分。

您将了解在此类开发中使用 Python 的优势，并熟悉 Python 生态系统中专门用于处理 LLM 的主要库和工具。最后，本章概述了课程的整体结构及其学习目标，让您对后续内容有所了解。
