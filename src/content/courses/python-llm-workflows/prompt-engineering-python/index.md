与大型语言模型的交互质量，很大程度上取决于所提供的输入内容。这种输入，即提示词，是引导模型行为的主要方式。准确设置提示词对于获得有用且准确的结果必不可少。

本章将着重介绍提示工程，特别是如何在 Python 中设计和实现有效的提示词。我们将介绍编写清晰指令的基本原则，包括通过示例引导模型的少样本技术。你将学会组织提示词的方式，以处理复杂任务并生成特定的输出格式。我们还将介绍如何使用 Python 基于应用程序状态或数据动态生成提示词，减少响应中不准确或虚构信息的办法，以及测试和改进提示词的迭代过程。

在本章结束时，你将掌握实用技术，用于直接在你的 Python 大型语言模型应用中构建和管理提示词，以提高它们的性能和可靠性。
