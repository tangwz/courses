在已经确定了关系型数据库的表、行和键的结构后，接下来要学习如何访问和操作在这些数据库中存储的数据。本章将介绍结构化查询语言 (SQL)，它是为此目的专门设计的标准语言。

您将学习进行基本数据操作所需的基本 SQL 命令：
*   使用 `SELECT` 语句从表中获取特定数据。
*   使用 `WHERE` 子句根据条件筛选获取的数据。
*   使用 `ORDER BY` 对查询结果进行排序。
*   使用 `INSERT` 语句向表中添加新记录。
*   使用 `UPDATE` 语句修改表中现有记录。
*   使用 `DELETE` 语句从表中删除记录。

重点是理解这些主要命令的语法和应用，让您能够进行与关系型数据库数据必要的交互。
