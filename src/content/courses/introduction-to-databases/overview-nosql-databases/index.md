在掌握了关系型数据库和 SQL 的知识后，我们现在关注不同的数据管理方式。尽管关系模型对于结构化数据很有效，但某些涉及大规模、高速度或非结构化信息的情况会从其他解决方案中获益。

本章介绍 NoSQL 数据库。我们将讨论它们发展的原因以及它们的普遍特点。您将了解几种主要的 NoSQL 数据库类型，包括：

*   **文档数据库：** 以灵活的文档状结构存储数据。
*   **键值存储：** 针对基于唯一键的快速查找进行了优化的简单模型。
*   **列族存储：** 按列而非行组织数据。
*   **图数据库：** 专门为管理高度关联的数据而设计。

最后，我们将简要比较 SQL 和 NoSQL 在数据存储和检索方式上的主要区别。
