本章介绍与大型语言模型（LLMs）交流的基本方法。首先，我们将回顾LLMs是什么以及它们在构建应用方面的核心能力。您将学习提示工程的定义以及它对引导LLM行为的重要性。

我们将分解有效提示的结构，明确指令、上下文和输入数据等主要组成部分。您将了解文本生成和摘要等任务的基本提示技巧。我们还将查看$temperature$和$top_p$等生成参数如何影响模型的输出。本章包含实践练习，供您尝试创建简单的提示并观察LLM的响应效果。
