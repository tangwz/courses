构建和维护数据基础设施需要一系列专门的工具。本章介绍数据工程工作流程中重要的软件和平台。您将学习在数据库中使用 SQL 进行数据操作，应用 Git 进行版本控制以管理代码，以及通过命令行界面（CLI）操作操作系统。我们还将概要介绍常见的云平台以及工作流调度器的作用。本章包含实践练习，从基本的 Git 命令开始，帮助您开始使用这些工具。
