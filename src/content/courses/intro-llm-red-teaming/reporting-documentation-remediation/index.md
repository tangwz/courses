识别和测试大型语言模型中的安全弱点后，接下来的步骤是有效传达这些发现并协助解决问题。本章涵盖了红队行动中评估后的重要阶段。

您将学习如何构建专门用于大型语言模型评估的详细红队报告。我们将介绍清晰阐述已识别弱点及其相关风险给各类相关方的方法。一个主要侧重将放在根据这些弱点的潜在影响进行优先级排序，使团队能够首先处理最重要的威胁。

此外，本章将指导您制定可行的缓解建议，并与开发团队合作以实施修复措施。您还将了解重新测试的流程，以验证已实施修复措施的有效性。最后，我们将讨论记录红队操作规程和成功攻击模式的重要性，以建立用于未来评估的知识库。本章以起草一份漏洞报告某个部分的实践练习作结。
