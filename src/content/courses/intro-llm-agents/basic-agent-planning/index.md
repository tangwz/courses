到目前为止，我们已审视了大型语言模型智能体如何被定义，以及它们如何使用大型语言模型、工具和记忆等核心组成部分。我们还演示了如何创建一个非常简单的智能体。现在，我们将注意力转向智能体行为中一个更动态的方面：它们如何决定做什么以及按什么顺序做。智能体若要真正有用，而不仅仅是简单的单步操作，它需要一种机制来制定并遵循计划以达成既定目标。

本章将介绍智能体规划与执行的基本方法。你将了解到：

*   规划在大型语言模型智能体背景下的一般理念，以及它对于完成需要多步任务的重要性。
*   像思维链提示这样的技术，它有助于引导智能体的推理过程。
*   ReAct（推理与行动）框架，这是一种结合智能体推理能力和执行行动能力的常见模式。
*   如何为你的智能体设定清晰目标，并将更复杂的任务分解成更简单、按顺序的行动。
*   观察智能体进展和管理执行过程中常见、简单失败的基本方法。

通过研习这些内容，你将掌握如何组织智能体的思维过程，使其能够处理并执行一系列行动以达到指定目标。
