本章介绍 Python 中用于数值计算和数据分析的主要库：NumPy 和 Pandas。这些工具为数据科学和人工智能应用中常用的许多数据准备和处理任务提供支持。

您将了解 NumPy 和 Pandas 是什么，并明白它们在典型数据工作流程中的重要性。我们将引导您设置开发环境，包括使用 `pip` 等常用包管理器或 Anaconda 等环境安装所需的库。您将使用这些库运行初步代码片段以验证安装，并熟悉 Jupyter Notebooks（一个用于交互式数据工作的标准工具）。本章以一个侧重于环境配置和初始库使用的实践练习结束。
