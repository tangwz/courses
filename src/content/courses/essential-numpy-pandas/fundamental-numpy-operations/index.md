建立了如何创建 NumPy 数组并访问其元素之后，下一步是使用它们进行计算。本章介绍 NumPy 在 Python 数值计算中的核心操作。

你将学会如何：

*   对数组进行逐元素的基本算术运算（如加法、减法、乘法）。
*   使用通用函数（ufuncs）进行优化过的向量化操作，例如 $sqrt(x)$ 或 $sin(x)$。
*   计算整个数组或沿特定轴的常见数学和统计量，例如求和、平均值和标准差。
*   执行数组之间或数组与标量值之间的逻辑比较。
*   理解广播（broadcasting），这是 NumPy 用于隐式处理形状不同但兼容的数组操作的机制。

这些操作对数据分析十分重要，并且是更复杂算法的组成部分。
