本章是您开始接触计算机视觉的章节。我们将从定义计算机视觉开始，阐述其目的，并讨论机器如何以不同于人类的方式处理视觉数据。我们将简要回顾历史背景，介绍相关情况，然后概述图像分类、目标检测等标准计算机视觉任务，并说明这些术语的含义。

您还将了解构成计算机视觉系统的常见软件和硬件构成。本章的主要实践目标是指导您使用常用库（特别是 OpenCV）搭建 Python 开发环境。最后，我们将通过一个实践环节，引导您使用刚搭建好的工具加载并显示您的第一张数字图像。学完本章，您将对计算机视觉有一个基本认识，并拥有一个可用于后续练习的工作环境。
