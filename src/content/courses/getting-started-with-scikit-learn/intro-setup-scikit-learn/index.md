本章介绍 Scikit-learn，这是一个在 Python 中进行机器学习的重要库。我们将首先说明 Scikit-learn 在 Python 科学计算环境中的位置，并引导您完成安装过程。

您将了解该库一致的 API 设计，并关注其主要组成部分：估计器 (Estimators)、预测器 (Predictors) 和转换器 (Transformers)。我们将介绍数据应如何组织以便与 Scikit-learn 配合使用，通常使用 NumPy 数组或 Pandas DataFrame。最后，您将看到如何加载该库提供的内置数据集，这些数据集对练习很有用。本章最后包含一个实践练习，以验证您的环境配置是否正常工作。
