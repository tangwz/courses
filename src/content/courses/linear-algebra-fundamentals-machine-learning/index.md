本课程为机器学习与人工智能奠定数学根基。内容从实务角度讲述线性代数的核心构成：向量、矩阵及其运算。你将习得这些数学构件如何表示数据并进行转换，这在诸多机器学习算法中是必做之务。本内容着重讲解直观思维与实际应用，借助Python及NumPy库将理论知识应用于实践。课程结束后，你将牢固掌握支撑现代人工智能的线性代数知识体系。
