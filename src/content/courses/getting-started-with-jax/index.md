学习 JAX，用于高性能数值计算和机器学习 (machine learning)研究。本课程涵盖 JAX 核心知识，包括其 NumPy 接口、`jit`、`grad`、`vmap` 和 `pmap` 等函数变换，以及用于状态管理的函数式编程模式。您将获得适配现代硬件（GPU/TPU）来加速和求导 Python 代码的实践经验。
