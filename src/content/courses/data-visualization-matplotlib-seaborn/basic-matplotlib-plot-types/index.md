在上一章学习了Matplotlib图形和坐标轴的基本构成之后，我们现在来制作一些适合常见数据分析工作的特定类型图表。本节侧重于生成旨在比较数量和了解数据分布的可视化图表。

您将学习：

*   使用`plt.bar()`和`plt.barh()`创建垂直和水平条形图，用于比较分类数据。
*   使用`plt.hist()`生成直方图，来呈现单个数值变量的频率分布，包括如何调整箱数。
*   使用`plt.pie()`制作饼图，以表示整体中的比例，同时考虑它们的局限性。
*   简单提及堆叠图，用于可视化构成部分的贡献。

学完本章后，您将能够选择和应用适合不同分析情境的基本Matplotlib图表类型。
