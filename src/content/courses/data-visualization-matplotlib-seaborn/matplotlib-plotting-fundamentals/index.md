既然你已经对 Matplotlib 有了基本了解，并且环境也已搭建完成，是时候开始有条理地创建图表了。本章将介绍在使用 Matplotlib 时会反复用到的主要知识点。

你将学习 Matplotlib 可视化的基本构成，特别是充当画布和绘图区域的 `Figure` 和 `Axes` 对象。我们将讲解使用 Python 脚本创建图表的典型工作流程。你将练习生成基本但实用的图表类型：线形图以显示趋势（例如绘制 $y$ 对 $x$ 的图），以及散点图以分析两个变量之间的关系。此外，你还将学习如何通过添加标题、坐标轴标签、自定义颜色和线条外观，以及设置特定的坐标轴范围来聚焦于特定数据区域，从而改进这些基本图表。到本章结束时，你将能够使用 Matplotlib 的基本工具创建并自定义简单且信息丰富的图表。
