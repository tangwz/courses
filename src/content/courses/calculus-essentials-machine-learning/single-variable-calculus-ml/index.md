在确立了理解机器学习中变化和优化的必要性之后，本章着重介绍最简单的情况：只有一个输入变量的函数。我们将从极限的定义开始，它为导数的严谨定义提供了依据。

您将学习如何计算导数，它表示函数 $f(x)$ 在特定点的瞬时变化率或斜率，通常表示为 $f'(x)$ 或 $\frac{dy}{dx}$。我们将介绍标准的求导法则（如幂法则、乘积法则和商法则），这是求常见函数导数所必需的。

我们将考察一个重要用途：使用导数来找到函数的最小值点和最大值点。这是理解优化算法如何改进机器学习模型的起点。最后，我们将通过使用 Python 库计算导数，把这些数学原理应用到实践中。
