本章为构建旨在自主运行的大语言模型应用提供了起始点。我们首先明确大语言模型语境下的“自主性”所指为何。然后，我们将分析构成自主系统的典型组成部分，包括核心模型、记忆结构、规划流程以及行动执行机制。

你将了解到设计这些系统时固有的难点，例如减轻不准确输出（幻觉）、实现有效的长程规划，以及达成与外部工具的可靠互动。最后，我们将从架构角度简要介绍LangChain、AutoGen和CrewAI等流行框架，它们常用于组装这些复杂的系统。
