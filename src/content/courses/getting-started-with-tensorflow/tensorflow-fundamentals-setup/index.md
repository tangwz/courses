本章介绍使用 TensorFlow 2.x 所需的基本知识和准备工作。我们首先将了解 TensorFlow 本身的结构和目的。您将学习如何使用 `pip` 和 `conda` 等常用工具配置开发环境。

我们将说明在 CPU 与 GPU 上运行 TensorFlow 计算的实际区别，以及如何相应地配置您的系统。按照设置说明，我们将提供验证安装是否正常工作的步骤，包括检查 GPU 是否可用。最后，我们将介绍更广泛的 TensorFlow 生态系统，简要提及 Keras 和 TensorBoard 等主要组成部分，它们将在后续章节中使用。本章完成后，您将拥有一个正确配置的 TensorFlow 环境。
