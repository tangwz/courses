前面的章节已经提供了构建完整的、基于文本的大语言模型应用（从生成、RAG到自主代理）所需的各项组成部分。最后一章将介绍一些专用功能，以帮助您进一步扩展您的应用。

您将接触到三个不同的主题：

*   **多模态输入**：学习如何使用视觉-语言模型处理图像和文本，摆脱纯文本交互的限制。
*   **应用评估**：利用内置工具，根据参考标准衡量您的大语言模型输出的性能，解决质量度量的难题。
*   **微调准备**：了解如何使用工具包的辅助函数来格式化自定义数据集，这是训练专用模型的第一步。

这些部分为将更高级的功能整合到您的项目中提供了一个实用的起点。
