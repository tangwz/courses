截至目前，你的Python脚本都是逐条顺序执行指令的。然而，大多数程序需要能够做出判断和重复操作。本章将介绍核心的程序结构，它们能让你引导代码的执行流程。

你将学会如何使用条件语句（`if`、`elif`、`else`），以便仅在满足特定条件时运行特定的代码块。你还将学习如何使用循环（`while`、`for`）来重复执行代码，无论是在条件为真时，还是遍历序列中的每个项目时。最后，我们将讨论如何使用`break`和`continue`来微调循环行为。掌握这些结构对于编写能够动态响应不同情况并高效处理重复性任务的程序来说，非常重要。
