尽管 Scikit-learn 提供了多种预置组件，但实际的机器学习项目常常需要根据具体需求定制数据处理步骤或模型算法。本章重点介绍如何通过构建自己的兼容组件来扩展 Scikit-learn 生态系统。

你将学习如何：
*   理解并遵循 Scikit-learn API 评估器和转换器的设计原则。
*   实现自定义转换器，用于独特的数据预处理或特征工程任务。
*   开发自定义评估器，以封装专门的模型逻辑。
*   应用面向对象原则，如组合和继承，以有效设计组件。
*   将适当的参数验证和管理纳入你的自定义类中。
*   将你的自定义组件顺畅地融入 Scikit-learn 流水线中。
*   使用策略和工具以彻底测试你的自定义评估器和转换器。

掌握这些技术后，你可以在熟悉的 Scikit-learn 框架内直接创建更灵活、可重用且专业的机器学习工作流程。实操部分将指导你从头开始构建一个自定义集成评估器。
