在充分掌握创建和整合基础工具后，我们将开始开发更专精和高阶的功能。本章会提供构建多种精巧工具的实践指南。

您将学习构建能让语言模型实现以下功能的工具：
*   解析并执行代码，特别注重安全沙箱的使用。
*   浏览网页并从页面中获取特定信息。
*   安全地执行文件系统操作，例如读写文件。
*   与用户界面交互，或针对复杂或敏感的决策请求人工介入。
*   生成格式良好的结构化数据，如 JSON 或 CSV。

这些高阶工具集显著扩展了代理处理更广泛任务的能力，并能使其与环境进行更灵活的互动。
