单个工具开发完成后，随之而来的问题是如何让LLM代理在特定情况下有效选择合适的工具，并协调多个工具进行更复杂的操作。本章将专门讨论这一点：LLM代理如何选择和排序工具。我们将研究代理驱动的工具选择方法、多步骤工具执行流程的设计，以及管理工具调用之间依赖关系的方法。你还将学习如何为工具使用实现条件逻辑，并处理顺序和并行工具执行的协调问题。
