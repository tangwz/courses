本章介绍机器学习。首先，我们会定义系统从数据中‘学习’意味着什么，并比较这种方法与传统编程技术的区别。你会看到机器学习的应用实例，并熟悉其主要类别：监督学习、无监督学习和强化学习。最后，我们将概述一个典型机器学习项目所包含的步骤，并介绍一些常用工具。
