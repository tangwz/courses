你可能想知道，在各种流行语和复杂算法充斥之下，你为什么要投入时间学习机器学习 (machine learning)？尤其是如果你才刚刚开始。答案很简单，机器学习正在从根本上改变我们与技术互动的方式以及企业的运营模式。理解其主要原理正在从一种小众专业变为数字时代的一项基本技能。

### 数据时代

我们生活在一个由数据定义的时代。网站、传感器、社交媒体、金融交易以及无数其他来源每秒都在生成海量信息。传统编程往往难以处理和理解这些海量数据。机器学习 (machine learning)提供了自动发现模式、进行预测并从这些数据中获取价值的方法，将原始信息转化为可操作的见解。学习机器学习使你能够在这个数据丰富的环境中高效工作。

### 自动化复杂任务

想想过滤垃圾邮件、推荐你可能喜欢的电影或翻译语言等任务。在这些情况下为每一种可能的情形编写明确的规则几乎是不可能的。机器学习 (machine learning)在这方面表现出色。机器学习系统不是通过显式编程，而是从示例中学习。这使得它们能够处理复杂性并适应新情况，这是传统程序无法做到的。通过学习机器学习，你获得了构建能够解决这类复杂、基于模式的问题的系统的能力。

### 影响各个行业

机器学习 (machine learning)并不仅限于科技巨头。它的影响几乎涵盖所有可想象的行业。

> 机器学习应用涵盖多个方面，推动创新和提高效率。

从改进医疗保健中的医学诊断和检测金融领域的欺诈交易，到优化交通运输中的物流以及个性化娱乐和零售体验，机器学习正在推动创新。理解基本知识使你能够识别在你感兴趣的或工作的方面中应用这些技术的机会。

### 提升你的技能和职业发展

即使你不打算成为一名专业的机器学习 (machine learning)工程师，掌握基本原理也越来越有价值。产品经理需要理解机器学习的能力来设计智能产品。分析师使用机器学习技术来获得更深刻的见解。软件工程师正在将机器学习模型整合到应用中。简历上具备机器学习知识可以显著提升你的职业前景，并为你打开通向构建下一代智能应用相关职位的机会。

### 解决问题的新方法

本质上，机器学习 (machine learning)提供了一套强大的解决问题新工具。它提供了预测、分类、聚类等方法，使你能够从不同的角度应对挑战，这种角度侧重于从数据中学习，而不是仅仅依靠显式指令。

掌握机器学习的基本概念，将为你提供一个扎实的起点。你将理解术语，掌握常见算法的主要思想，并领会构建和评估简单模型的过程。这些基本知识对于你无论是想简单地理解塑造我们未来的技术，还是最终构建复杂的AI系统，都非常重要。能够“教”计算机从数据中学习是一项强大的技能，而它始于理解基本知识。
