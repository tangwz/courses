# 强化学习导论

来源：[强化学习导论](https://apxml.com/zh/courses/intro-to-reinforcement-learning)

学习强化学习 (reinforcement learning)（RL）的基本原理，包括马尔可可夫决策过程、Q学习、SARSA以及深度Q网络概览。本课程提供理论知识和实践应用能力，用于构建通过与环境交互学习最优行为的智能体。适合具有机器学习 (machine learning)基本知识的工程师和开发人员。

预计学时：24 小时

先修要求：机器学习和Python编程知识

## 学习目标

- **强化学习基本原理**：理解强化学习的核心组成部分：智能体、环境、状态、动作、奖励、策略。
- **马尔可夫决策过程**：使用MDPs表述问题并理解其性质。
- **值函数与贝尔曼方程**：掌握状态值函数和动作值函数的原理并推导贝尔曼方程。
- **无模型学习**：实现并区分蒙特卡洛和时序差分学习方法（Q学习、SARSA）。
- **函数逼近**：在强化学习中应用函数逼近技术，处理大规模状态空间。
- **深度Q网络（DQN）**：理解DQN的基本原理及其组成部分，如经验回放。
- **强化学习实现**：使用Python和相关库构建并训练简单的强化学习智能体。
