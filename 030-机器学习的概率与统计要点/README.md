- **概率基本原理**：应用主要的概率知识，如条件概率、贝叶斯定理和随机变量，解决数据问题。
- **概率分布**：识别并应用常用概率分布（正态、泊松、二项等），用于机器学习中的数据建模。
- **描述性统计**：计算并理解集中趋势、离散度和相关性指标，以总结数据集。
- **统计推断**：理解抽样方法、中心极限定理，并构建总体参数的置信区间。
- **假设检验**：制定并执行假设检验（如t检验），以便基于数据做决策并评估模型。
- **回归分析**：掌握线性回归的基本原理，将模型拟合到数据，并评估其表现。
- **实际操作**：使用Python库（如NumPy、SciPy和Pandas）进行统计技术和概率计算。
