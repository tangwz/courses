# 自然语言处理基本原理

来源：[自然语言处理基本原理](https://apxml.com/zh/courses/nlp-fundamentals)

本课程系统讲解自然语言处理（NLP）技术。学员将学习文本预处理、特征工程、分类以及序列建模和词嵌入 (embedding)的基本知识。使用常用库和方法构建实用NLP应用。要求熟悉Python编程和机器学习 (machine learning)的基本知识。

预计学时：18 小时

先修要求：熟悉Python编程和机器学习入门知识。

## 学习目标

- **文本预处理**：应用高级文本清洗和标准化技术，以适应各种NLP任务。
- **特征工程**：掌握并理解特征提取方法，如TF-IDF和N-gram，用于文本表示。
- **文本分类**：构建、训练和评估机器学习模型，以解决文本分类问题。
- **词嵌入**：理解分布式语义学背后的原理，并应用Word2Vec和GloVe等技术。
