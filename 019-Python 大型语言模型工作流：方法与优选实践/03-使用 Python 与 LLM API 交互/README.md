# 第 3 章：使用 Python 与 LLM API 交互

来源：[原章节](https://apxml.com/zh/courses/python-llm-workflows/chapter-3-interacting-llm-apis-python)

[返回课程目录](../README.md)

在开发环境配置完成后，下一步是实现 Python 代码与大型语言模型之间的通信。本章侧重于讲解使用 Python 与 LLM 应用程序编程接口 (API) 交互的具体操作。

你将学习 API 请求和响应的结构，如何使用标准 `requests` 库发送请求，以及处理返回数据或错误的方法。我们还将介绍 LLM 供应商提供的官方 Python 客户端库的使用、不同的认证方式，以及管理 API 调用频率限制和使用成本等实际考量。学完本章后，你将能够以编程方式向 LLM 发送提示并获取它们的输出。
