# 计算机视觉导论

来源：[计算机视觉导论](https://apxml.com/zh/courses/introduction-to-computer-vision)

预计学时：9 小时

先修要求：具备基本编程能力为佳

## 学习目标

- **核心思想**：理解计算机视觉的定义及其主要目标。
- **图像表示**：阐述数字图像如何由计算机表示和存储。
- **图像处理**：执行基本的图像操作和滤镜任务。
- **特征检测**：描述检测边缘和角点等特征的基本方法。
- **物体识别思路**：掌握图像中物体识别的基本原理。
- **开发环境配置**：配置用于计算机视觉任务的基本Python环境，并使用常用库。
