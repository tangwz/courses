# 精通梯度提升算法

来源：[精通梯度提升算法](https://apxml.com/zh/courses/mastering-gradient-boosting-algorithms)

一本关于高级梯度提升技术、实现与优化的全面指南。通过本课程，您将透彻理解XGBoost、LightGBM和CatBoost等算法，并学习如何有效地将其应用于复杂的机器学习 (machine learning)问题。本课程内容包括梯度提升模型的理论原理、实际实现细节、高级正则化 (regularization)方法、超参数 (parameter) (hyperparameter)调优策略以及模型可解释性。

预计学时：28 小时

先修要求：Python编程与机器学习入门

## 学习目标

- **梯度提升理论**：理解梯度提升机器（GBMs）的数学原理和算法细节。
- **高级算法实现**：使用XGBoost、LightGBM和CatBoost各自的库进行算法实现与配置。
- **正则化技术**：应用专为提升算法设计的高级正则化方法，以防止过拟合。
- **超参数优化**：采用精细策略调优梯度提升模型的超参数，以达到最佳性能。
- **模型解释**：运用SHAP等技术，解释复杂梯度提升模型的预测结果和运行表现。
- **性能优化**：优化梯度提升模型，使其在大数据集上实现速度、内存占用和预测准确度的提升。
- **模型定制**：在提升框架中实现自定义损失函数和评估指标。
