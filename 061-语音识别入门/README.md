# 语音识别入门

来源：[语音识别入门](https://apxml.com/zh/courses/introduction-to-speech-recognition)

本课程全面介绍自动语音识别（ASR）的基本原理。从计算机处理音频的基本原则讲起，您将学习标准的ASR流程，包含信号处理、特征提取、声学模型构建和语言模型构建。课程内容讲解清晰，步骤实用，助您明白口语如何转化为文字。结课时，您将掌握使用现有ASR工具以及处理本领域较复杂议题的必备知识。

预计学时：14 小时

先修要求：熟悉Python基础知识有益。

- **ASR基础知识**：掌握现代语音识别流程的主要组成部分，从音频输入到文本输出。
- **音频处理**：学习如何为机器学习应用处理、清理并提取数字音频信号的特征。
- **模型原理**：理解声学模型和语言模型在解读口语中的作用。
- **实践操作**：使用流行的Python库和预训练模型，构建一个可运行的语音识别应用。
