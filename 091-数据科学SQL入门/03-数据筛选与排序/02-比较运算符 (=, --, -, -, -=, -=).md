# 比较运算符 (=, <>, <, >, <=, >=)

来源：[原文](https://apxml.com/zh/courses/sql-for-data-science/chapter-3-filtering-sorting-data/comparison-operators)

[返回章节目录](README.md) · [返回课程目录](../README.md)

比较运算符是定义 `WHERE` 子句中特定条件的主要工具。`WHERE` 子句用于根据特定条件筛选行。这些运算符允许你将列中的值与特定值或另一列进行比较，形成精确数据筛选的依据。

可以把这些运算符看作你向数据提出的问题。这个值是否 *等于* 那个值？这个数字是否 *大于* 那个数字？SQL 使用标准符号进行这些比较。

### 等于运算符 (=)

等于号（`=`）检查列中的值是否与你指定的值完全相等。这可能是最常用的比较方式。

**语法：**
`WHERE column_name = value`

**示例：**
假设我们有一个 `customers` 表，想找到所有居住在“波士顿”市的客户。

```sql
SELECT
    customer_id,
    first_name,
    last_name,
    city
FROM
    customers
WHERE
    city = 'Boston';
```

此查询扫描 `customers` 表中的 `city` 列，并只返回 `city` 值为“波士顿”的行。请注意，文本值（如“Boston”）通常用单引号括起来。

### 不等于运算符 (<> 或 !=)

要查找列值与特定值 *不* 相等的行，请使用不等于运算符。标准 SQL 使用 `<>`（小于号后跟大于号），但许多数据库系统也接受 `!=`（感叹号后跟等于号）来实现相同目的。两者都得到相同的结果：筛选掉与指定值匹配的行。

**语法：**
`WHERE column_name <> value`
or
`WHERE column_name != value`

**示例：**
让我们查找所有 *不住在* “波士顿”的客户。

```sql
SELECT
    customer_id,
    first_name,
    last_name,
    city
FROM
    customers
WHERE
    city <> 'Boston'; -- 或者使用 city != 'Boston'
```

此查询返回 `customers` 表中除 `city` 为“波士顿”之外的所有行。

### 大于运算符 (>)

大于运算符（`>`）选择列中值在数值上或字母顺序上大于指定值的行。

**语法：**
`WHERE column_name > value`

**示例：**
设想一个具有 `price` 列的 `products` 表。要查找所有价格超过 50.00 美元的产品：

```sql
SELECT
    product_name,
    price
FROM
    products
WHERE
    price > 50.00;
```

这会获取价格严格大于 50.00 的产品。它不包含价格恰好为 50.00 美元的产品。

### 小于运算符 (<)

反之，小于运算符（`<`）查找列值小于指定值的行。

**语法：**
`WHERE column_name < value`

**示例：**
要从具有 `stock_quantity` 列的 `products` 表中查找库存少于 10 件的产品：

```sql
SELECT
    product_name,
    stock_quantity
FROM
    products
WHERE
    stock_quantity < 10;
```

这会返回库存量为 9、8、7 等的产品，但不包括库存量为 10 的产品。

### 大于或等于运算符 (>=)

有时你需要在比较中包含边界值。大于或等于运算符（`>=`）选择列中值大于 *或* 恰好等于指定值的行。

**语法：**
`WHERE column_name >= value`

**示例：**
查找价格为 50.00 美元或更高的产品：

```sql
SELECT
    product_name,
    price
FROM
    products
WHERE
    price >= 50.00;
```

此查询包含价格恰好为 50.00 美元的产品，以及价格更高的产品。

### 小于或等于运算符 (<=)

类似地，小于或等于运算符（`<=`）选择列中值小于 *或* 恰好等于指定值的行。

**语法：**
`WHERE column_name <= value`

**示例：**
在 `customers` 表中使用 `signup_date` 列，查找在 2023 年 1 月 1 日或之前注册的客户：

```sql
SELECT
    customer_id,
    first_name,
    signup_date
FROM
    customers
WHERE
    signup_date <= '2023-01-01';
```

此查询获取注册日期为 2023 年 1 月 1 日或之前的客户。日期值通常也用单引号括起来，常采用“YYYY-MM-DD”格式。

### 不同数据类型的比较

这些比较运算符能自然地用于不同类型的数据：

- **数字：** 根据其数值进行比较（例如，100 > 50）。
- **字符串（文本）：** 根据数据库使用的字符集按字母顺序进行比较（例如，“Apple”<“Banana”）。比较通常从左到右逐个字符进行。请记住，字符串比较可能是区分大小写或不区分大小写的，具体取决于特定的数据库系统及其配置（“boston”可能不等于“Boston”）。
- **日期/时间：** 按时间顺序进行比较（例如，'2023-01-15' > '2023-01-10'）。

这六个比较运算符构成了 SQL 中筛选数据的依据。通过将它们与 `WHERE` 子句结合使用，你可以精确地定位分析所需的特定行。在接下来的部分中，我们将了解如何组合多个条件并处理更复杂的筛选情况。
