# 机器学习线性代数基础

来源：[机器学习线性代数基础](https://apxml.com/zh/courses/linear-algebra-fundamentals-machine-learning)

本课程为机器学习与人工智能奠定数学根基。内容从实务角度讲述线性代数的核心构成：向量、矩阵及其运算。你将习得这些数学构件如何表示数据并进行转换，这在诸多机器学习算法中是必做之务。本内容着重讲解直观思维与实际应用，借助Python及NumPy库将理论知识应用于实践。课程结束后，你将牢固掌握支撑现代人工智能的线性代数知识体系。

预计学时：10 小时

先修要求：Python基础知识有助益。

## 学习目标

- **用向量和矩阵表示数据**：习得如何用向量和矩阵表示数据点、特征以及完整数据集。
- **实施核心线性代数运算**：进行向量加法、点积、矩阵乘法和转置等主干运算。
- **诠释几何变换**：直观感受矩阵如何作为函数对向量空间进行旋转、缩放和切变。
- **求解线性方程组**：建立并求解线性方程组，此为优化和模型拟合中的普遍工作。
- **习得特征值和特征向量**：习得特征值和特征向量的知识体系及其在主成分分析 (PCA) 等算法中的作用。
- **在Python中实施知识点**：运用Python中的NumPy库高效地进行线性代数计算。
