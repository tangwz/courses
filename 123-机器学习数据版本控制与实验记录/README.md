先修要求：需具备Python和机器学习基础。

## 学习目标

- **理解核心要点**：掌握机器学习生命周期中数据版本控制和实验记录的重要性与基本原理。
- **实现数据版本控制**：应用数据版本控制（DVC）来管理数据集，追踪变化，并确保数据可复现性。
- **实现实验记录**：运用MLflow Tracking记录机器学习实验的参数、指标、代码版本和产出物。
- **工具整合**：将数据版本控制与实验记录整合为一个统一的MLOps工作流程。
- **构建可复现流水线**：构建机器学习项目的结构，以提升复现性、协作效率和调试能力。
