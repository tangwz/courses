## 学习目标

- **理解数据质量**：认识到洁净数据的重要性，并识别常见的数据质量问题类型。
- **处理缺失数据**：学习检测和处理数据集中缺失值的基本方法。
- **管理重复数据**：识别并移除数据中的重复记录。
- **修正数据类型**：理解不同数据类型，以及如何将列转换为其适当的格式。
- **基本数据格式化**：应用简单的格式化方法以保持一致性。
- **应用基本方法**：使用常用工具（如Python库）执行基本的数据清洗任务。
