# 数据工程导论

来源：[数据工程导论](https://apxml.com/zh/courses/intro-data-engineering)

本课程提供数据工程原理的基本知识。学习数据如何被收集、存储、处理及管理，以支持数据分析和人工智能应用。熟悉数据管道、存储系统以及数据工程师日常使用的工具。

预计学时：15 小时

先修要求：无

## 学习目标

- **核心思想**：定义数据工程，并将其与数据科学、数据分析等相关职位区别开来。
- **数据生命周期**：了解数据生命周期所包含的阶段，从生成到存储和处理。
- **数据管道**：阐述数据管道的原理，包括ETL和ELT处理流程。
- **数据存储**：识别不同类型的数据存储方案，例如数据库、数据仓库和数据湖。
- **数据处理**：描述批量数据处理和流式数据处理之间的区别。
- **常用工具**：认识数据工程中常用的工具，包括SQL和版本控制。
