# 应用数据科学：方法与实践

来源：[应用数据科学：方法与实践](https://apxml.com/zh/courses/applied-data-science)

本课程讲授应用数据科学的实用方法。学员可在已有知识之上，解决复杂数据难题，内容涵盖数据准备、特征处理、模型构建、评估及部署要点。本课程面向具备数据科学入门知识和Python技能的人群。

预计学时：40 小时

先修要求：Python和数据科学入门知识。

## 学习目标

- **高级数据准备**：实施复杂方法，用于清洗、转换及整合不同数据集。
- **特征处理**：从原始数据中创建并筛选有益特征，以提升模型性能。
- **模型构建与调优**：应用并调整各类有监督与无监督学习算法。
- **模型评估**：运用恰当的度量标准和验证策略，评估并比较模型表现。
- **部署要点**：了解使用API和容器准备及部署机器学习模型的基础知识。
