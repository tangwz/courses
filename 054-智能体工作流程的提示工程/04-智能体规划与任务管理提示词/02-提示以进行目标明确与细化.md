# 提示以进行目标明确与细化

来源：[原文](https://apxml.com/zh/courses/prompt-engineering-agentic-workflows/chapter-4-prompts-agent-planning-task-management/prompting-goal-specification-refinement)

[返回章节目录](README.md) · [返回课程目录](../README.md)

有效的代理规划始于对所需完成事项的清晰理解。详细说明了如何使用提示工程 (prompt engineering)来引导AI代理理解、明确并细化其目标。一个明确定义的目标是成功多步骤计划的根基；没有它，代理的行动可能会变得不集中且低效。

## 从明确目标开始

当你指示AI代理时，你提供的初始目标是其后续行为的主要驱动力。在此阶段的模糊性可能导致与你预期结果的明显偏差。因此，编写能够清晰表达代理目标的提示是一项核心技能。

### 目标表述的精准性

在你的提示中用于定义目标的语言应尽可能精准。模糊的术语可能被大型语言模型（LLM）以多种方式解读，从而导致不可预测的计划。

思考以下差异：

- **模糊目标：** “管理我的电子邮件。”
- **精准目标：** “扫描我收件箱中过去24小时内收到的电子邮件。识别与‘阿尔法项目’相关或来自‘[client@example.com](mailto:client@example.com)’的邮件。用一句话总结每封已识别的邮件，并将其标记 (token)为‘紧急审阅’。”

为实现精准性：

1. **具体化：** 清晰地说明代理需要完成什么。
2. **尽可能量化 (quantization)：** 如果目标涉及数量、持续时间或其他可衡量方面，请将其包含在内。例如，“分析*最近的5条*客户评价”优于“分析客户评价”。
3. **明确范围：** 清晰勾勒任务的界限。应包含什么，以及同样重要的是，应排除什么？

### 使用结构化格式设定目标

对于更复杂的目标，或在提供与目标相关的多项信息时，提示中的结构化格式可以极大地帮助代理理解。像JSON、XML甚至简单的Markdown列表这样的格式可以帮助划分目标的不同方面。

例如，指示代理规划内容创作日程：

```
你的任务是生成一个内容计划。以下是详细信息：
目标：为一款新的健身应用创建为期4周的内容日历。
目标受众：25-40岁的初级到中级健身爱好者。
内容支柱：
  - 锻炼方案（居家、健身房）
  - 营养建议（膳食准备、健康零食）
  - 励志内容（成功案例、心态）
平台：博客和Instagram
输出：一个包含以下列的表格：周、日、主题、平台、简要描述。
```

这种结构化方法比单一的散文段落更能帮助代理可靠地解析要求。

### 纳入负面约束

有时，明确代理*不应*做什么与明确它应该做什么同等重要。这些通常被称为负面约束。

示例：
“研究我们新CRM软件的竞品。侧重于功能、定价和用户评价。*不包括2022年之前推出的产品。*”
这有助于缩小代理的搜索范围，并防止在不相关信息上浪费精力。

## 提示进行迭代式目标澄清

用户经常提供高级、模糊或不完整的目标。一个高级代理不应仅仅失败或随意猜测。相反，它应该能够识别模糊性并寻求澄清。你的提示可以引导这个细化过程。

代理提出澄清问题的能力使其从一个简单的指令执行者转变为一个更具协作性的伙伴。

> 目标明确与细化的一种典型交互流程。提示引导代理处理初始目标，检查其清晰度，并在必要时请求更多细节，然后进入规划阶段。

### 指示代理识别模糊性

你可以明确指示代理分析目标是否存在潜在误解。

提示片段：
`“审阅以下用户请求：‘[用户请求]’。识别任何模糊或未充分具体化的术语或短语。如果发现模糊之处，向用户提出最多三个有针对性的问题，以澄清请求，然后再进行规划。”`

例如，如果用户说“找一家好的本地意大利餐厅”，代理在这样的提示引导下，可能会问：

1. “‘本地’是什么意思？请指定一个社区或最大距离。”
2. “你对‘好’的价位有什么考虑（例如，\$, 
   $$
   ,
   $$
   \$）？”
3. “我需要考虑任何特定的意大利菜肴或饮食要求吗？”

### 引导逐步细化

对于复杂请求，一次澄清可能不足。你可以设计鼓励多步骤细化对话的提示。

提示结构想法：

```
初始用户目标：[用户目标]

代理指令：
1.  陈述你对初始用户目标的当前理解。
2.  列出你为解释此目标所做的任何假设。
3.  如果目标不够清晰以创建详细计划，请向用户提出一个精准问题进行澄清。
4.  等待用户反馈。如果提供了反馈，根据新信息重新评估目标并从步骤1重复。
```

这种方法创建了一个循环，代理在每次交互中逐步细化其对目标的理解。

### 设定“充分明确”目标的标准

为了帮助代理知道何时信息充足，你可以在提示中提供构成明确目标所需的标准。

旅行规划代理示例：
`“如果旅行请求包含：目的地（城市或地区）、旅行日期（或日期范围）、旅行人数和大致预算，则认为其已充分明确。如果用户请求中缺少这些信息，你必须要求他们提供。”`

这为代理提供了一个核对清单，以便在进入规划阶段之前验证目标的完整性。

## 面向目标的提示的实际示例

让我们看几个场景来说明这些技巧。

### 场景1：细化模糊的研究任务

- **初始用户请求：** “告诉我关于可持续能源的信息。”
- **代理任务（通过提示）：**

  ```
  用户想了解可持续能源。这是一个广泛的话题。
  你的目标是将此请求细化为一个更具体的信息目标。

  考虑以下方面，如果用户意图不明确，请提出问题：
  1.  具体类型：用户是对太阳能、风能、地热能、水力发电感兴趣，还是希望进行比较？
  2.  背景：他们是对全球趋势、特定区域发展、技术进展、经济可行性还是政策感兴趣？
  3.  信息深度：他们是想要简要概述、详细报告还是近期新闻文章？
  4.  目的：这是为了常识、特定项目还是投资研究？

  根据你的最佳理解提出一个细化后的目标陈述，或者提出最多2个澄清问题。例如：“你对太阳能的最新技术进展感兴趣，还是更希望了解不同可持续能源类型及其当前的全球采纳率？”
  ```

此提示引导代理主动将用户广泛的兴趣缩小为一个可管理且可执行的目标。

### 场景2：明确多组件项目

- **初始用户请求：** “帮我发布我的新播客。”
- **代理任务（通过提示）：**

  ```
  用户想要发布一个新的播客。这涉及多个组成部分。
  为了有效协助，我们需要定义范围和核心要素。

  将“播客发布”目标分解为以下子目标。对于每个子目标，如果用户未提供详细信息，你应该设法获取：
  -   **播客主题/细分定位：** 播客是关于什么的？目标受众是谁？
  -   **格式与时长：** 基于访谈、个人讲述、小组讨论？平均每集时长？
  -   **初始内容：** 前3-5集的想法？
  -   **技术要求：** 录音设备、编辑软件、托管平台？（如果用户不确定，请提供建议）
  -   **品牌：** 播客名称、封面艺术想法、片头/片尾音乐？
  -   **发布时间线：** 期望的发布日期或时间范围？

  你的第一步是与用户确认这些方面，或询问缺失的信息。例如：“为了帮助你发布播客，能否告诉我更多关于其主题以及你的目标受众是谁？另外，你对前几集有什么想法吗？”
  ```

在这里，提示帮助代理理解“发布播客”并非单一行动，而是一个需要明确多个不同信息片段的项目。

## 对规划和执行的影响

投入在提示清晰目标明确和细化上的努力，在随后的规划和执行阶段会带来丰厚回报。当代理以一个充分理解且精准定义的目标开始时：

- **任务分解更精准：** 代理能够更有效地将目标分解为逻辑上合理、可实现的分支任务。
- **工具选择更具针对性：** 如果代理需要使用外部工具（如搜索引擎、计算器或API），清晰的目标有助于其选择最合适的工具。
- **资源分配更优化：** 代理能更好地估计计划每个部分所需的精力和资源。
- **重新规划最小化：** 对初始目标的误解是计划失败和需要大量重新规划的常见原因。清晰的目标可降低这种可能性。

通过掌握引导目标明确和细化的提示，你使你的AI代理能够以更高的精准度和可靠性处理复杂任务，最终实现更成功、更高效的自动化工作流程。
