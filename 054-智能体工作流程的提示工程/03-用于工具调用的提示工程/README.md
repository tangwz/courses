# 第 3 章：用于工具调用的提示工程

来源：[原章节](https://apxml.com/zh/courses/prompt-engineering-agentic-workflows/chapter-3-prompt-engineering-tool-use)

[返回课程目录](../README.md)

AI代理通常需要获取语言模型本身不直接具备的外部信息或功能。为了执行诸如网页搜索、执行计算或与数据库交互等操作，代理必须能够使用工具。本章介绍使AI代理能够选择、操作和管理这些外部工具的提示工程技术。

具体来说，您将学习到：
*   扩展外部工具的语言模型背后的基本原理。
*   引导代理进行工具选择和正确操作的提示技巧。
*   使大型语言模型能够理解的工具描述和API规范格式化方法。
*   如何使用提示来管理工具的输入以及从工具接收到的输出。
*   提示代理与API交互并处理其响应的方法。
*   用于帮助代理处理工具执行中发生错误的提示设计。
*   在代理系统中集成新颖或自定义开发的工具的提示创建策略。

掌握这些技术将使您能够设计出提示，通过将您的代理连接到更广泛的资源和功能，从而大幅增强它们的能力。
