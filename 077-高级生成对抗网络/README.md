# 高级生成对抗网络

来源：[高级生成对抗网络](https://apxml.com/zh/courses/generative-adversarial-networks-gans)

构建精密的生成对抗网络（GAN）。本课程涵盖高级架构，处理模式崩溃等复杂训练难题，并阐述严格的评估指标。实现前沿的 GAN 变体，并理解支撑现代生成模型的理论原理。适合致力于推进生成式人工智能发展的工程师和研究人员。

预计学时：40 小时

先修要求：中级机器学习，需掌握Python

## 学习目标

- **高级架构**：实现并分析 StyleGAN、BigGAN 和 CycleGAN 等精密 GAN 架构。
- **训练稳定性**：应用 Wasserstein 损失、梯度惩罚和谱归一化等方法，使 GAN 训练稳定。
- **条件生成**：构建并训练条件 GAN (cGAN) 和信息最大化 GAN (InfoGAN)，以实现受控数据合成。
- **模型评估**：使用并解释 Fréchet Inception Distance (FID) 和 Inception Score (IS) 等高级指标，用于 GAN 性能评估。
- **理论理解**：理解高级 GAN 方法背后的数学原理和理论依据。
- **实现能力**：培养使用标准深度学习框架实现、训练和调试复杂 GAN 模型的能力。
