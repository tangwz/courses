# 第 4 章：性能、可扩展性与优化

来源：[原章节](https://apxml.com/zh/courses/feature-stores-for-ml/chapter-4-performance-scalability-optimization)

[返回课程目录](../README.md)

一个可用的特征平台是必需的，但一个生产环境可用的特征平台还必须在负载下高效运行，并随着数据量和请求量的增长而有效扩展。本章讨论确保您的特征平台满足这些运行需求的实用方面。

我们将介绍通过基准测试系统评估性能的方法。您将学习最小化在线特征检索延迟以及针对大规模数据集扩展离线特征计算任务的技巧。此外，我们考虑优化存储使用、管理运行成本、设计高可用性和灾难恢复的策略，并进行容量规划和负载测试，以准备应对未来的需求。
