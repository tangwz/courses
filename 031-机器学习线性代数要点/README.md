# 机器学习线性代数要点

来源：[机器学习线性代数要点](https://apxml.com/zh/courses/linear-algebra-essentials-ml)

建立机器学习 (machine learning)算法理解与实现的牢固根基，学习核心线性代数知识。本课程涵盖向量 (vector)、矩阵、线性方程组、向量空间、特征值、特征向量以及奇异值分解（SVD）等矩阵分解方法，侧重其在机器学习场景中的应用，并使用NumPy等Python库进行实践。

预计学时：16 小时

先修要求：基础数学与Python

## 学习目标

- **向量与矩阵运算**：使用NumPy进行向量与矩阵运算，并理解其与数据表示及变换相关的几何含义。
- **求解线性方程组**：理解线性方程组如何在机器学习中产生，并使用矩阵方法求解。
- **向量空间**：掌握向量空间、基、维度及线性独立性，理解其在特征空间中的体现。
- **特征值与特征向量**：计算并解析特征值与特征向量，理解它们在主成分分析（PCA）等算法中的重要性。
- **矩阵分解**：应用奇异值分解（SVD）等矩阵分解方法，用于降维等任务。
- **实现能力**：将线性代数知识转化为实际Python代码，使用NumPy和SciPy等库。
