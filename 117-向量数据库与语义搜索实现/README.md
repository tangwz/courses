# 向量数据库与语义搜索实现

来源：[向量数据库与语义搜索实现](https://apxml.com/zh/courses/vector-databases-semantic-search)

学习构建和部署基于向量 (vector)数据库的语义搜索系统。本课程涵盖向量嵌入 (embedding)、近似最近邻 (ANN) 算法、数据库结构以及常用工具的实践操作。培养您所需的能力，以制作能理解内容而非仅匹配关键词的应用。

预计学时：20 小时

先修要求：Python基础, 数据知识。

## 学习目标

- **向量嵌入**：掌握不同数据类型向量嵌入模型的生成与应用。
- **向量数据库架构**：阐述现代向量数据库的核心组成部分和设计原则。
- **ANN算法**：比较并区分不同的近似最近邻搜索算法及其权衡点。
- **语义搜索流程**：设计并搭建数据索引和执行语义查询的流程。
- **实践操作**：运用流行的向量数据库库和平台，构建功能完善的语义搜索应用。
- **性能调优**：评估并调整索引参数，以达到最佳搜索性能和资源使用效率。
