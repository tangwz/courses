# 第 4 章：组织数据：集合类型

来源：[原章节](https://apxml.com/zh/courses/python-for-beginners/chapter-4-organizing-data-collections)

[返回课程目录](../README.md)

你已经学习了如何使用变量和数字、字符串、布尔值等基本类型来处理单个数据。但大多数程序需要处理成组的相关数据。将每个数据项存储在单独的变量中很快会变得不方便。

本章将介绍Python的内置集合类型，它们提供了存储和管理多个数据项的有效方法。你将学习：

*   **列表 (Lists)：** 有序、可变序列，用于存储可以更改、添加或移除项的集合。
*   **元组 (Tuples)：** 有序、不可变序列，当集合中的项在创建后不应更改时很有用。
*   **字典 (Dictionaries)：** 无序集合，以键值对形式存储数据，允许根据唯一键快速查找数据。
*   **集合 (Sets)：** 无序集合，只存储唯一项，用于成员资格测试和去除重复项。

理解如何有效使用这些不同结构对于在Python程序中组织数据很重要。我们将讲解如何创建、访问、修改（如果适用），以及为不同编程场景选择合适的集合类型。
