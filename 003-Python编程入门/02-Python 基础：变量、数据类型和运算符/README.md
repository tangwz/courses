# 第 2 章：Python 基础：变量、数据类型和运算符

来源：[原章节](https://apxml.com/zh/courses/python-for-beginners/chapter-2-python-basics-variables-data-types-operators)

[返回课程目录](../README.md)

Python 环境搭建完成后，我们将进入编写程序所必需的基本内容学习。本章会讲解在脚本中管理和处理数据所需的基础知识。

你将学会如何：
*   使用 **变量** 来存储和引用信息。
*   使用 Python 的基本 **数据类型**：数字（如整数`5`和浮点数`3.14`）、文本（如字符串`"hello"`）和布尔值（`True` 和 `False`）。
*   应用 **运算符** 进行算术运算（$a + b$）、比较（$x > y$）和逻辑组合（`condition1 and condition2`）。
*   在不同类型之间转换数据（例如，将`"10"`转换为`10`）。
*   接收与脚本互动的用户输入。
*   添加注释来解释你的代码。

到本章结束时，你将能够编写简单的 Python 程序，进行计算，处理基本文本，并与用户输入进行交互。
