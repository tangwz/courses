# 第 1 章：Python 入门

来源：[原章节](https://apxml.com/zh/courses/python-for-beginners/chapter-1-getting-started-with-python)

[返回课程目录](../README.md)

本章提供开始Python编程所需的初始步骤。我们将介绍Python是什么，为何它是一种广泛使用的语言，尤其在人工智能和网页开发等方向，以及解释型语言和编译型语言之间的区别。

你将学会如何：
*   在 Windows、macOS 和 Linux 操作系统上安装 Python。
*   与 Python 解释器 (REPL) 进行交互。
*   编写并运行你的第一个简单 Python 脚本。
*   熟悉适用于 Python 开发的集成开发环境 (IDE) 和代码编辑器。

学完本章，你将拥有一个可用的 Python 环境，并具备运行基本 Python 代码的经验。
