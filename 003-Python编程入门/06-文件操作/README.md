# 第 6 章：文件操作

来源：[原章节](https://apxml.com/zh/courses/python-for-beginners/chapter-6-interacting-with-files)

[返回课程目录](../README.md)

应用程序经常需要在多次运行之间保存信息，或从外部读取配置数据。处理存储在操作系统上的文件是处理持久性数据的一项基本技能。到目前为止，我们使用过的数据结构和变量在脚本运行时只存在于计算机内存中。本章将介绍 Python 中的文件输入/输出 (I/O) 操作。

您将学习如何：
*   理解文件路径以及 Python 如何找到文件。
*   使用不同模式（读取、写入、追加）打开文件。
*   从现有文本文件中读取数据。
*   向文本文件写入新数据。
*   向现有文件末尾追加数据。
*   使用 `with` 语句进行更安全的文件处理，确保文件正确关闭。
