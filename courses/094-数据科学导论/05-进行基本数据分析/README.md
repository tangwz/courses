# 第 5 章：进行基本数据分析

来源：[原章节](https://apxml.com/zh/courses/introduction-to-data-science/chapter-5-basic-data-analysis)

[返回课程目录](../README.md)

数据收集和准备完毕后，下一步是开始提取有价值的信息。本章将介绍用于分析数据集的基本方法。

您将学习如何开始进行数据初步分析（EDA），以了解数据的主要特征。我们将介绍计算和解释汇总统计量的方法，包括均值、中位数（$M_e$）和众数等集中趋势度量，以及极差、方差（$s^2$）和标准差（$\sigma$）等离散程度度量。

后续章节将阐述频率分布及其在描述数据规律中的作用。一个重要的讨论点是相关性与因果关系之间的区别，这是分析中常见的混淆之处。您还将初步了解如何建立和检验假设。本章最后将有一个动手实践环节，侧重于计算这些基本统计量。
