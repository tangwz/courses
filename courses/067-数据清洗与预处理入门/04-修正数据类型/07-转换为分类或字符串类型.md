# 转换为分类或字符串类型

来源：[原文](https://apxml.com/zh/courses/intro-data-cleaning-preprocessing/chapter-4-correcting-data-types/converting-to-categorical-string)

[返回章节目录](README.md) · [返回课程目录](../README.md)

虽然将列转换为数值或日期时间格式可以处理定量和时间数据，但许多数据集包含最适合表示为文本或不同类别的信息。确保这些列具有适当的类型对于准确的分析和建模同样重要。有时，看起来是数字的数据，如邮政编码或产品ID，其作用更像是一个标签，不应用于数学计算。其他时候，文本数据代表不同的组或类。

### 字符串：通用文本类型

文本数据最一般的类型通常称为 `string`（在像 pandas 这样的库中有时也叫 `object`）。这种类型适用于任何字符序列：姓名、地址、自由格式描述、唯一标识符等。如果某一列包含文本，并且你需要执行文本特有的操作，如搜索子字符串、拆分文本，或者只是按原样存储，那么将其转换为字符串类型通常是第一步。

许多数据加载工具可能会正确识别文本列，但有时数值ID或代码可能会被错误地读取为数字。如果你有一列，比如 `ProductID`，包含 `1001`、`1002`、`2001` 等值，而这些只是标识符，那么对它们进行求平均等数学运算就没有意义。你应该确保这一列被视为文本。

在 Python 的 pandas 库中，你可以使用 `.astype()` 方法将列转换为字符串类型：

```python
# 假设 'df' 是你的 DataFrame，'ProductID' 是列名
df['ProductID'] = df['ProductID'].astype(str)

# 验证更改
print(df['ProductID'].dtype)
# 输出可能是：object 或 string[pyarrow]，具体取决于 pandas 版本/设置
```

这种转换确保了像 `1001` 这样的值被视为文本序列 '1001'，而不是整数 1001。

### 分类数据：表示群组

通常，字符串列只包含少量唯一值，这些值代表不同的组或类别。例子包括像 `Status`（'Pending'、'Completed'、'Failed'）、`SurveyResponse`（'Agree'、'Neutral'、'Disagree'）或 `ProductCategory`（'Electronics'、'Clothing'、'Groceries'）这样的列。

虽然你可以将其存储为字符串，但将其转换为特定的 `categorical` 数据类型可以带来一些好处，尤其是在像 pandas 这样的工具中：

1. **内存效率：** 如果你有很多行但只有少量唯一的字符串值（例如，大型全球数据集中的“国家”列），将其存储为类别可以显著减少内存使用。在内部，数据以整数形式存储，这些整数映射到唯一的字符串值。
2. **性能：** 对分类数据进行的操作有时会比对字符串数据进行的操作更快。
3. **分析支持：** 一些统计模型和可视化库会识别分类数据并进行适当处理（例如，确保在图表中正确排序，如“低”、“中”、“高”）。

你可以将列转换为分类类型，同样使用 `.astype()`：

```python
# 假设 'df' 是你的 DataFrame，'Status' 是列名
df['Status'] = df['Status'].astype('category')

# 验证更改
print(df['Status'].dtype)
# 输出：category

# 你可以查看唯一的类别
print(df['Status'].cat.categories)
# 输出可能是：Index(['Completed', 'Failed', 'Pending'], dtype='object')
```

### 何时选择字符串类型与分类类型

- **在以下情况使用 `string`：**
  - 列包含高度唯一的文本值（例如，用户评论、街道地址）。
  - 你需要经常执行复杂的字符串操作（正则表达式、拆分等）。
  - 唯一值的数量相对于行数非常大。
- **在以下情况使用 `categorical`：**
  - 列具有有限的、固定的唯一值集合，这些值经常重复出现（例如，状态码、评分、组标签）。
  - 内存使用是一个重要考量。
  - 你希望明确定义可能的值或它们的顺序。

将作为文本或类别使用的列转换为正确的类型（`string` 或 `categorical`）可以防止不正确的数学操作，并能优化内存使用和性能。它确保你的数据准确反映其所表示信息的本质，为可靠的分析做好准备。
