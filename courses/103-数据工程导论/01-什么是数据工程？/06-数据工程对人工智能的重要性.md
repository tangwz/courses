# 数据工程对人工智能的重要性

来源：[原文](https://apxml.com/zh/courses/intro-data-engineering/chapter-1-what-is-data-engineering/why-data-engineering-matters-for-ai)

[返回章节目录](README.md) · [返回课程目录](../README.md)

人工智能（AI）和机器学习 (machine learning)（ML）系统从数据中学习。数据的质量、可访问性和结构直接决定了这些系统的表现。可以把它想象成建造房屋：你需要坚固、准备好的材料来搭建牢固的结构。数据工程为AI提供了这些必需的材料。没有有效的数据工程，AI项目通常会遇到困难或完全失败。

你可能在计算中听过“垃圾进，垃圾出”（GIGO）这句话。这对AI来说尤其如此。如果AI模型使用不准确、不完整或格式不佳的数据进行训练，它的预测和决策会反映出这些缺点。数据工程直接处理这个基本难题。

以下是数据工程活动如何直接支持人工智能开发：

1. **数据收集与引入：** AI模型通常需要来自不同来源（数据库、日志、传感器、API等）的海量数据。数据工程师构建系统以可靠地收集这些原始数据。没有这第一步，AI将无法学习。
2. **数据清洗与准备：** 原始数据很少能直接使用。它可能包含错误、缺失值、不一致或不相关的信息。数据工程师清洗和预处理这些数据，确保其准确和一致。这个清洗步骤很重要，因为它直接影响AI模型的可靠性。
3. **数据转换与特征工程：** AI模型需要特定格式的数据。数据工程师转换数据，可能通过改变其结构、组合不同数据源，或从现有数据中创建新的*特征*（输入变量），以帮助模型更有效地学习。这种准备使得数据对算法而言易于理解和有用。
4. **构建数据管道：** AI模型需要持续提供新的、干净的数据，无论是用于初始训练还是后续运行（推理 (inference)）。数据工程师设计、构建和维护自动化数据管道（如稍后讨论的ETL/ELT过程），以确保数据从源系统到AI应用流畅可靠地流动。
5. **数据存储与访问：** 准备好的数据需要高效存储，以便AI模型能够快速访问它进行训练和预测。数据工程师选择和管理适合的存储方案（如数据仓库或数据湖），以适应AI系统所需的规模和访问模式。

可伸缩性是另一个重要的考量。AI应用，特别是深度学习 (deep learning)模型，通常需要庞大的数据集。数据工程实践和工具旨在处理大规模数据，确保即使数据量增加，系统也能保持良好性能。

实质上，数据工程构建并维护AI所依赖的数据基础设施。它确保为AI提供的数据是可信、可访问且符合其目的的。数据科学家侧重于构建模型和提取洞察，而数据工程师则确保基础数据工作正确完成，从而使成功的AI应用成为可能。没有可靠的数据工程，即使是最复杂的AI算法也无法发挥其全部作用。

- [Fundamentals of Data Engineering: Planning and Building Robust Data Systems](https://books.google.com/books/about/Fundamentals_of_Data_Engineering.html?id=z1F7EAAAQBAJ) — Joe Reis, Matt Housley (2022)
  Publisher: O'Reilly Media
  提供数据工程原则的全面概述，涵盖数据管道、存储和为分析及人工智能应用做准备。
- [Designing Machine Learning Systems: An Iterative Process for Production-Ready Applications](https://www.oreilly.com/library/view/designing-machine-learning/9781098107952/) — Chip Huyen (2022)
  Publisher: O'Reilly Media
  探讨构建和部署机器学习模型的系统级方面，重点关注数据基础设施、特征工程和MLOps实践。
- [Hidden Technical Debt in Machine Learning Systems](https://papers.nips.cc/paper/5656-hidden-technical-debt-in-machine-learning-systems.pdf) — D. Sculley, Gary Holt, Daniel Golovin, Eugene Davydov, Todd Phillips, Dietmar Ebner, Vinay Chaudhary, Michael Young, Jean-François Crespo, Dan Dennison (2015)
  Journal: Advances in Neural Information Processing Systems (NIPS 2015); Publisher: Neural Information Processing Systems Foundation, Inc. (NeurIPS); Volume: 28; Pages: 2503-2511
  一篇基础论文，强调了构建和维护生产级机器学习系统所面临的挑战和成本，尤其侧重于数据依赖性以及对可靠数据管理的需求。
