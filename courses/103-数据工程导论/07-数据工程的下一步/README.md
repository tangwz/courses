# 第 7 章：数据工程的下一步

来源：[原章节](https://apxml.com/zh/courses/intro-data-engineering/chapter-7-next-steps-data-engineering)

[返回课程目录](../README.md)

您现在已学习了数据工程的基本原理，从定义角色到理解数据管道、存储、处理以及必要的工具。本章将着重指导您在该方向上的持续发展。

我们将讨论后续学习的潜在方向，提出构建作品项目的建议方法，并讨论为开源做出贡献的益处。此外，我们将介绍跟上数据工程中不断发展变化的工具和技术的方法，并对本课程所讲述的要点进行简要回顾。这为应用和拓展您已获得的基本知识指明了方向。
