## 学习目标

- **NumPy 数组**：创建、操作并在NumPy N维数组上进行数学运算。
- **数组索引**：使用各种索引方法，选择和修改NumPy数组中的数据子集。
- **Pandas 数据结构**：理解并使用Pandas Series和DataFrames，它们是数据分析的常见结构。
- **数据加载与保存**：从常见文件格式（如CSV、Excel）读取数据到Pandas数据框，并保存处理后的数据。
- **数据清洗**：使用Pandas处理缺失值并进行基本数据清洗操作。
- **数据选择**：使用标签、位置和条件，从Pandas数据框中选择行和列。
- **数据聚合**：使用Pandas的groupby功能分组数据并计算汇总统计量。
- **数据合并**：在Pandas中使用连接和合并方法，组合来自多个来源的数据。
