# 第 1 章：介绍与首次文本生成

来源：[原章节](https://apxml.com/zh/courses/getting-started-with-llm-toolkit/chapter-1-foundational-text-generation)

[返回课程目录](../README.md)

本章介绍 Kerb 工具包的主要组成部分，并讲解生成文本的流程。在构建RAG或智能体等复杂系统之前，需要建立一种清晰且可重复的方式与大型语言模型沟通。我们将着重于使用工具包的配置和生成模块来创建这种连接。

在本章中，您将学会：

*   设置用于本课程的本地开发环境。
*   了解工具包主要组成部分的设计原则。
*   通过统一接口配置多个大型语言模型提供商，例如OpenAI和Anthropic。
*   执行标准API调用以从模型获取文本响应。
*   处理需要实时反馈的应用程序的流式输出。
