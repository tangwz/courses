# 第 4 章：高级编排与工作流构建

来源：[原章节](https://apxml.com/zh/courses/multi-agent-llm-systems-design-implementation/chapter-4-advanced-orchestration-workflows)

[返回课程目录](../README.md)

独立的LLM智能体，即使具备沟通能力，也需要有结构的协作来解决复杂、多步骤的问题。本章将讨论编排这些智能体团队的难题。我们将研究如何构建精细的工作流，以规定智能体间的协作方式。你将了解到多种编排模型，包括状态驱动和基于图的方法、适应性任务规划的方法，以及确保系统可靠性和容错能力的策略。此外，我们还将讨论人工参与流程的整合，以及管理大型智能体群的技术。
