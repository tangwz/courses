# 设计与实现多智能体大型语言模型系统

来源：[设计与实现多智能体大型语言模型系统](https://apxml.com/zh/courses/multi-agent-llm-systems-design-implementation)

本课程全面介绍如何设计与实现基于大型语言模型（LLM）的多智能体系统。学员将学习先进的架构模式、智能体间通信策略、复杂工作流程编排以及有效的评估方法。通过实践指导与动手操作环节，您将掌握构建与管理精巧人工智能智能体团队的技能，使之能够协作解决问题和执行任务。本课程面向希望使用大型语言模型构建具备多个交互智能体的高级应用的工程师和开发人员。

预计学时：48 小时

先修要求：熟悉Python和LLM。

## 学习目标

- **先进智能体架构**：设计适用于多智能体大型语言模型系统的复杂且可扩展的架构。
- **智能体间通信**：实现大型语言模型智能体之间有效的通信与协调协议。
- **精巧智能体角色**：开发具有专门角色、记忆及工具使用能力的智能体。
- **工作流程编排**：构建与管理涉及多个协作智能体的复杂工作流程。
- **集体推理**：实现智能体之间集体推理与分布式问题解决的策略。
- **系统优化与评估**：评估、调试并优化多智能体大型语言模型系统的性能与成本效益。
