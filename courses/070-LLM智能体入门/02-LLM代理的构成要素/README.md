# 第 2 章：LLM代理的构成要素

来源：[原章节](https://apxml.com/zh/courses/intro-llm-agents/chapter-2-llm-agent-building-blocks)

[返回课程目录](../README.md)

在明确了LLM代理是什么之后，我们将审视它们的内部结构。本章将LLM代理分解为其基本组成部分。您将了解到：

*   作为代理认知核心的大型语言模型（LLM）。
*   指令和提示是如何编写以指导代理行为的。
*   工具在扩展代理能力以与外部系统互动方面的作用。
*   短期记忆在操作过程中保持上下文信息的理念。
*   代理用于规划和安排行动的基本方法。
*   定义代理运作的观察、思考和行动的循环过程。

了解这些独立部分以及它们如何协同运作，对于理解代理如何处理信息并完成目标非常重要。
