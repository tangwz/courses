# 第 3 章：你的第一个LLM智能体：循序渐进指南

来源：[原章节](https://apxml.com/zh/courses/intro-llm-agents/chapter-3-your-first-llm-agent)

[返回课程目录](../README.md)

在了解了LLM智能体是什么以及它们的构成要素之后，本章将从理论转向实践。在这里，你将运用这些基础知识，构建你的第一个简单LLM智能体。

你将学会：
*   为智能体搭建准备开发环境。
*   选择一个适合基础智能体的大语言模型。
*   为你的智能体拟定指令并设定明确的目标。
*   在智能体的代码中实现一个基本动作。
*   运行你的智能体并观察其运作。
*   识别并处理常见的初期问题。

本章最后将有一个动手实践环节，你将构建一个待办事项管理智能体，从而巩固这些实际操作步骤。
