# Julia 语言用于机器学习

来源：[Julia 语言用于机器学习](https://apxml.com/zh/courses/julia-for-machine-learning)

本课程教授您如何使用Julia编程语言进行机器学习 (machine learning)任务。它以编程和机器学习的知识为起点，引导您学习Julia的特有功能和库，使其成为机器学习开发中的有力选择。您将学会在Julia中实现各种机器学习模型和数据处理流程。

预计学时：32 小时

先修要求：编程与机器学习基础知识
