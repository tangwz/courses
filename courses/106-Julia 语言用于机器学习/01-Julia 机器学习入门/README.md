# 第 1 章：Julia 机器学习入门

来源：[原章节](https://apxml.com/zh/courses/julia-for-machine-learning/chapter-1-julia-ml-getting-started)

[返回课程目录](../README.md)

本章将带您开始使用 Julia 进行机器学习。我们首先会考察 Julia 为何非常适合机器学习任务，尤其是其在科学计算方面的性能优势和特点。接着，您将配置 Julia 开发环境，安装 Julia 语言及其主要的软件包。之后，我们将介绍 Julia 的类型系统和多重派发机制，以及数据操作所需的基本语法。本章还会引导您学习如何使用数组、矩阵，以及用于处理表格数据的 DataFrames.jl 软件包。最后，您将学习使用 Julia 内置的包管理器 Pkg.jl 来管理项目依赖。
