## 学习目标

- **进阶架构**：运用 LangChain 进阶功能，设计并实现精巧的多步骤链和智能体。
- **记忆管理**：选择并配置合适的记忆机制，以保持长期会话上下文。
- **数据获取优化**：架构并优化用于生产规模的检索增强生成（RAG）流程。
- **评估与监控**：运用 LangSmith 等工具，为 LangChain 应用实施全面的评估、监控和可观测性。
- **优化与扩展**：为 LLM 应用应用性能优化技术和成本管理策略。
- **部署策略**：运用容器化和云原生技术，打包、部署和扩展 LangChain 应用。
- **安全实现**：在 LangChain 应用的整个生命周期中，融入安全优良实践。
