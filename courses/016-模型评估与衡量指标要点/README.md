## 学习目标

- **模型评价的目的**：掌握为何评价机器学习模型对开发工作十分必要。
- **分类衡量指标**：辨识并计算准确率、精确率、召回率和F1分数等主要衡量指标。
- **回归衡量指标**：辨识并计算MAE、MSE、RMSE和R平方等主要衡量指标。
- **混淆矩阵**：分析混淆矩阵以掌握分类表现。
- **数据划分**：学习训练/测试集划分对可靠模型评价的重要性。
- **简单评价流程**：应用一个简单流程，使用恰当的衡量指标评价模型。
