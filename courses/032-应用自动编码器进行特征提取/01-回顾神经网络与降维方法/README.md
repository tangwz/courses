# 第 1 章：回顾神经网络与降维方法

来源：[原章节](https://apxml.com/zh/courses/applied-autoencoders-feature-extraction/chapter-1-nn-dimensionality-reduction-recap)

[返回课程目录](../README.md)

为了有效使用自动编码器进行特征提取，需要扎实掌握底层神经网络机制和降维技术。本章将回顾这些基础主题，确保您在构建更复杂的模型之前具备所需知识。我们将这些通用思路与自动编码器如何学习和表示数据联系起来。

本章具体包括：
*   快速回顾神经网络组成部分：层、激活函数、损失函数和优化器。
*   与高维数据相关的难题，常被称为“维度灾难”。
*   介绍不同的降维方法。
*   线性（例如：PCA）与非线性降维的区别。
*   特征提取在机器学习流程中的作用。
*   设置基于Python的深度学习环境的步骤。
*   一个实现主成分分析（PCA）的实践练习。
