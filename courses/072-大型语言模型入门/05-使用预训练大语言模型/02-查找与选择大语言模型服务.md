# 查找与选择大语言模型服务

来源：[原文](https://apxml.com/zh/courses/intro-large-language-models/chapter-5-using-pre-trained-llms/finding-choosing-llm-service)

[返回章节目录](README.md) · [返回课程目录](../README.md)

既然您已理解从预训练 (pre-training)模型起步的益处，下一步便是了解去哪里获取它们以及如何挑选一个进行试用。好消息是，有许多可选方案，从简单的网页界面到更复杂的开发者平台。对于初学者，最适合起步的通常是交互简单直接的服务。

### 在哪里可以找到大语言模型 (LLM)服务？

几类平台提供了访问预训练 (pre-training)大语言模型的途径。以下是常见分类：

1. **模型提供商直属平台：** 许多开发大语言模型的机构都提供自己的平台。这些平台常包含用户友好的网页界面，有时称为“操场”或“工作室”，您可以在其中直接在浏览器中输入提示并查看结果，无需编写任何代码。例子有OpenAI平台（提供GPT-4等模型的访问）、Google AI Studio（用于Gemini模型）、Anthropic的Console（用于Claude模型）以及Cohere平台。这些是极佳的起步地点，因为它们专为试用而设，并且常为新用户提供慷慨的免费层级或初始额度。
2. **主要云服务提供商：** 像亚马逊网络服务（AWS）、谷歌云平台（GCP）和微软Azure这样的公司，通过AWS Bedrock、Google Vertex AI和Azure AI服务（包括Azure OpenAI）等，提供各种大语言模型（包括它们自己的和第三方的模型）的访问。这些平台虽然功能强大且可扩展，但通常更侧重于开发应用程序的开发者，相比模型提供商直属平台的操场，起初的学习曲线可能稍陡。然而，它们是行业中的重要平台。
3. **模型中心：** 像Hugging Face这样的平台是数千个预训练模型的中心库，其中包括许多开放获取模型。Hugging Face不仅列出模型，还常提供工具、数据集，甚至托管的“空间”或“推理 (inference)端点”，您可以在其中试用模型，有时直接在浏览器中或通过简单的API调用。它是用于试用提供商所供模型的宝贵资源。
4. **消费者应用：** 您可能已经通过ChatGPT、Google Gemini（网页应用）或Claude的网页界面等流行应用程序接触过大语言模型。虽然这些主要是面向最终用户应用，但与它们交互是感受大语言模型功能的极佳方式。请记住，使用消费者应用程序不同于通过应用程序编程接口（API）使用底层模型*服务*，后者提供更多控制，也是构建应用程序时的重点。

### 如何选择服务：初学者考量因素

既然有多种选择，您如何挑选一个开始呢？以下是一些值得考虑的因素，请记住您才刚刚起步：

- **易用性：** 优先选择带有清晰网页界面（操场）的平台。注册流程有多简单？您是否能在几分钟内开始试用，而无需配置复杂设置或预付付款信息？良好的文档和面向初学者的教程也很有帮助。
- **成本：** 寻找提供免费试用、初始额度或适合基本试用的持续免费层级的服务。大多数服务都采用按需付费模式，通常根据处理的文本量（以令牌计量，这在第2章已讨论过）收费。在大量使用前了解定价模式，但对于初始学习，请侧重于免费选项。
- **模型可得性：** 平台是否提供访问那些能力强且适合一般任务的模型？作为初学者，您可能会需要一个通用的指令遵循或聊天模型。通用模型与专用模型、或开放模型与封闭模型之间的区别（在第4章中有所提及），随着您学到更多可能会影响您的选择，但请从便捷性开始。
- **学习资源：** 查看平台是否提供专门针对初学者的教程、指南或示例。活跃的社区论坛也可以提供帮助。

### 推荐的起步方法

不要急于立即选择“完美”的平台。在此阶段的目标是试用和学习。

1. **从操场开始：** 从提供基于网页的操场服务开始。这样可以帮助您侧重于编写提示（如第3章所述）和理解模型行为，而无需担心代码。
2. **使用免费层级：** 充分利用免费额度或层级进行试用，无需财务投入。注意这些免费选项的任何使用限制。
3. **挑选一两个：** 避免让自己感到不知所措。选择一两个看起来易于使用的平台，并从那里开始。随着您理解加深，您随时可以尝试其他平台。
4. **侧重于交互：** 接下来的章节将引导您使用这些网页界面并进行首次基本API调用。首先要集中精力理解该交互过程。

找到合适的服务并非只关乎一个最佳选择，更多是关于找到一个舒适的环境，在其中您可以边做边学。您在一个平台上在提示编写和理解模型响应方面形成的技能，大部分可应用于其他平台。
