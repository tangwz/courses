# 第 1 章：了解大型语言模型

来源：[原章节](https://apxml.com/zh/courses/intro-large-language-models/chapter-1-understanding-large-language-models)

[返回课程目录](../README.md)

要有效使用大型语言模型（LLM），有必要建立一个基本认识。本章将大型语言模型（LLM）放在人工智能（AI）和自然语言处理（NLP）的背景中，从而为您构建这一基本认识。

您将了解大型语言模型的定义，概要了解它们如何从文本数据中学习，并看到它们通常执行的任务示例。我们还将处理一些关于其能力的常见误解。本章结束时，您将对大型语言模型是什么以及它们与更广泛的计算理论之间的关系有一个更清晰的认识。
