# Git 入门

来源：[Git 入门](https://apxml.com/zh/courses/getting-started-with-git)

学习 Git 版本控制的基本知识。本课程分步介绍如何使用重要的 Git 命令有效管理代码、跟踪改动以及与他人协作。开始高效管理您的软件项目。

预计学时：9 小时

先修要求：无需先修知识。

## 学习目标

- **版本控制基本原理**：理解 Git 等版本控制系统的作用与优点。
- **Git 仓库管理**：初始化新的 Git 仓库并理解其结构。
- **追踪改动**：学习 Git 的核心工作流程：暂存改动（`git add`）和保存快照（`git commit`）。
- **查看历史记录**：查看项目历史（`git log`）并比较不同文件版本（`git diff`）。
- **分支与合并**：使用分支管理不同的开发线并将其合并。
- **远程协作**：使用 `git clone`、`git push` 和 `git pull` 等命令与远程仓库进行交互。
