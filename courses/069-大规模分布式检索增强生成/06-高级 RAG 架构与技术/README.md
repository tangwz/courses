# 第 6 章：高级 RAG 架构与技术

来源：[原章节](https://apxml.com/zh/courses/large-scale-distributed-rag/chapter-6-advanced-rag-architectures-techniques)

[返回课程目录](../README.md)

前面的章节详细介绍了分布式检索增强生成系统的构建和扩展。现在，我们将转向能解决更复杂问题和信息需求的架构模式。本节侧重于扩展标准 RAG 实现功能的高级设计。

你将学习如何：
*   实现多跳和迭代式 RAG 以支持多步推理。
*   开发能使用分布式工具和服务的智能体式 RAG 系统。
*   在分布式环境中将知识图谱与 RAG 集成，以提升上下文理解。
*   通过反馈循环设计自我纠正和自我改进的 RAG 系统。
*   调整 RAG 系统以处理高度动态的信息和流式数据。
*   处理大规模 RAG 部署特有的安全问题。
*   构建适用于多种内容类型的跨语言和多模态 RAG 系统。

本章结束时，你将有能力为更广泛的高要求应用设计 RAG 解决方案。
