来源：[原章节](https://apxml.com/zh/courses/introduction-to-databases/chapter-5-working-with-databases)

在介绍过不同数据库模型（包括关系型SQL和NoSQL类型）的基本原理后，本章将侧重于它们的实际使用步骤。

我们将考察为特定需求选择数据库系统时需要考虑的准则。您将了解便于数据库操作的常用软件工具。本章将说明建立数据库实例连接的通用流程。最后，我们将介绍如何访问或配置一个简单的数据库环境，使您能够通过动手实践的连接与查询练习，应用所学知识。
