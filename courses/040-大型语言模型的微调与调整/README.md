# 大型语言模型的微调与调整

来源：[大型语言模型的微调与调整](https://apxml.com/zh/courses/fine-tuning-adapting-large-language-models)

掌握针对特定任务与应用方向定制预训练 (pre-training)大型语言模型的高级能力。本课程讲授先进的微调 (fine-tuning)方法、参数 (parameter)高效微调技术（PEFT）、数据准备策略及严谨的模型评估实践。通过动手实践，学员将学习如何优化大型语言模型性能，有效管理计算资源，并根据专业需求调整模型。

预计学时：28 小时

先修要求：机器学习与Transformer基础知识

## 学习目标

- **高阶微调策略**：实践并区分全量微调与各类参数高效微调（PEFT）方法。
- **调整模型的数据准备**：为指令微调和特定方向调整构建高质量数据集，并应对数据质量与数量的难题。
- **PEFT技术应用**：应用如LoRA、QLoRA和Adapter模块等技术，以高效调整大型模型。
- **训练优化**：使用梯度累积和混合精度训练等技术，优化微调过程以提升计算效率。
- **模型评估**：对微调模型进行全面评估，审视其在标准指标之外的表现，包含指令遵循和偏差分析。
- **部署考量**：分析微调后大型语言模型部署的实际要点，包括模型序列化和模型服务策略。
