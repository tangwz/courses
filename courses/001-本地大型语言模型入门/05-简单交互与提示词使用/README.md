# 第 5 章：简单交互与提示词使用

来源：[原章节](https://apxml.com/zh/courses/getting-started-local-llms/chapter-5-basic-interaction-prompting)

[返回课程目录](../README.md)

你已经搭建好环境，并成功运行了一个本地大型语言模型。下一步是有效地与它交流。本章将讲解与大型语言模型交互的核心方法：提示词使用。

你将学习如何组织你的输入，也就是提示词，以便从模型中获得你想要的结果。我们将介绍如何提问简单的问题、给出诸如总结等任务的指令，并理解上下文窗口，它决定了模型能记住多少对话内容。我们还会简单介绍一些设置，比如 $temperature$，它们会影响生成文本的随机性。学完本章，你就能与你的本地大型语言模型进行简单互动了。
