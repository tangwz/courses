# 本地大型语言模型入门

来源：[本地大型语言模型入门](https://apxml.com/zh/courses/getting-started-local-llms)

学习如何在个人电脑上直接运行大型语言模型的基本方法。本课程提供一步步的指导，教你如何配置运行环境、选择模型，并与你的首个本地大模型进行互动。理解本地大型语言模型背后的原理，无需具备专门的预备知识。

预计学时：5 小时

先修要求：具备基础电脑操作能力

## 学习目标

- **理解本地大型语言模型**：阐述大型语言模型是什么，以及在本地运行它们的益处。
- **环境配置**：明确硬件方面的考量，并配置运行本地大型语言模型所需的软件。
- **模型选择**：根据模型大小、运行表现和许可规定，查找并选择适合本地使用的大型语言模型。
- **基础互动**：使用常用工具加载并与本地大型语言模型进行互动，完成简单的文本生成任务。
- **基础提示词编写**：编写基础提示词，以引导本地大型语言模型生成文本内容。
