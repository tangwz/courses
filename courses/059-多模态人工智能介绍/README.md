# 多模态人工智能介绍

来源：[多模态人工智能介绍](https://apxml.com/zh/courses/intro-to-multimodal-ai)

本课程介绍多模态人工智能的核心原理。您将学习人工智能系统如何理解并处理来自文本、图像、音频等多种来源的信息。我们将讲解多模态人工智能系统的基本构成要素、常用方法和简单应用。本课程为所有对人工智能如何结合不同类型数据感兴趣的人士打下良好基础。

预计学时：10 小时

先修要求：无人工智能预备知识。

## 学习目标

- **多模态人工智能的核心原理**：理解多模态人工智能是什么、它的重要性以及所涉及的不同数据模态。
- **数据表示法**：识别文本、图像、音频和视频数据如何表示以便人工智能处理。
- **模态信息整合技术**：了解结合不同模态信息的常用方法，例如信息结合策略和表征学习。
- **多模态模型的构成要素**：识别构建简单多模态人工智能模型所用的基本组成部分。
- **基本应用**：熟悉多模态人工智能的入门应用，例如图像标注和视觉问答。
