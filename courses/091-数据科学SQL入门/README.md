# 数据科学SQL入门

预计学时：7 小时

先修要求：无需先修知识。

## 学习目标

- **数据库原理**：了解关系型数据库基本原理，如表、列、行和主键。
- **数据获取**：使用SELECT语句编写SQL查询，从数据库表中获取特定数据。
- **数据筛选与排序**：使用WHERE子句筛选数据，并使用ORDER BY子句对结果排序。
- **数据汇总**：使用聚合函数（如COUNT、SUM、AVG、MIN和MAX）对数据进行基本计算。
- **数据联接**：使用INNER JOIN子句联接多个表的数据。
- **基本数据操作（可选）**：理解数据插入、更新和删除的原理（尽管侧重于查询）。
