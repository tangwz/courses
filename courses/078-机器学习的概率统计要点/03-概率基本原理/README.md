# 第 3 章：概率基本原理

来源：[原章节](https://apxml.com/zh/courses/probability-statistics-fundamentals-ml/chapter-3-basic-probability)

[返回课程目录](../README.md)

在前一章学习了如何汇总数据之后，我们现在转向概率的原理。本章介绍了用于对不确定性进行推理的数学框架，这是许多机器学习模型和方法中的一个核心组成部分。

您将学习如何定义和计算基本概率，理解样本空间和事件的含义，并使用集合论符号表示概率规则。我们将涉及条件概率，即一个事件在另一个事件发生后，其发生可能性如何变化的情况（表示为 $P(A|B)$），并区分独立事件和相关事件。最后，您将对贝叶斯定理有一个初步认识，这是一个在整个统计学和机器学习中被广泛应用的重要结论。本章最后附有练习题，以帮助巩固这些知识点。
