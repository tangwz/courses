# 特征工程介绍

来源：[特征工程介绍](https://apxml.com/zh/courses/intro-feature-engineering)

学习将原始数据转化为机器学习 (machine learning)模型有用特征的必要技术。本课程涵盖数据准备、特征创建、缩放、编码和选择方法，并会应用Pandas和Scikit-learn等Python库。

预计学时：15 小时

先修要求：Python基础，需掌握Pandas。

## 学习目标

- **数据准备**：实施妥善处理缺失数据和异常值的方案。
- **特征转换**：对数值特征应用多种缩放和转换技术。
- **分类特征编码**：比较并应用不同方法对分类变量进行编码。
- **特征创建**：使用交互项和多项式特征，从现有数据生成新特征。
- **特征选择**：应用过滤法、包裹法和嵌入法选择相关特征。
- **实践应用**：在实际场景中，应用Pandas和Scikit-learn进行特征工程。
