# 第 2 章：数字图像基本原理

来源：[原章节](https://apxml.com/zh/courses/introduction-to-computer-vision/chapter-2-digital-image-fundamentals)

[返回课程目录](../README.md)

在对计算机视觉的目标有了初步认识后，我们现在来看看计算机处理的核心要素：数字图像。本章将讲解图像是如何表示和组织以便计算机处理的。

您将学习到：

*   **像素：** 任何数字图像的基本构成单元。
*   **图像表示：** 像素值是如何以数字形式存储的。
*   **颜色空间：** 理解不同的模型，例如灰度、RGB（$Red$、$Green$、$Blue$）和HSV（$Hue$、$Saturation$、$Value$）。
*   **文件格式：** JPEG和PNG等常见类型及其特点。
*   **分辨率和坐标：** 定义图像大小以及如何确定像素位置。

我们还将介绍将图像文件读入程序并检查其基本属性（例如尺寸和颜色通道）的实际步骤。在进行图像操作和分析之前，掌握这些基本原理很重要。
