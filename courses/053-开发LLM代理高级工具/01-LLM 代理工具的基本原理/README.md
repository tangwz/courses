# 第 1 章：LLM 代理工具的基本原理

来源：[原章节](https://apxml.com/zh/courses/building-advanced-llm-agent-tools/chapter-1-llm-agent-tooling-foundations)

[返回课程目录](../README.md)

本章为构建LLM代理能使用的工具奠定基础。它介绍工具在提升代理能力方面的作用、与LLM进行有效互动的设计原则，以及安全和错误处理的必要考量。

你将学会定义工具规范，并编写清晰的描述，使代理能理解并使用它们。我们还将讲解工具界面设计、有效组织输入和输出数据、实施错误处理策略，以及为你的工具应用安全措施。为了将这些想法付诸实践，本章包含创建你的第一个工具定义的指导。
