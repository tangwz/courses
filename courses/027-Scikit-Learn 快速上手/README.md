# Scikit-Learn 快速上手

来源：[Scikit-Learn 快速上手](https://apxml.com/zh/courses/getting-started-with-scikit-learn)

使用流行的 Python 库 Scikit-learn 构建实用机器学习模型。本课程介绍基础知识、数据处理、模型训练、评估，并使用管道构建流畅的工作流程。通过动手实践，你将学会运用常见算法处理分类和回归问题。

预计学时：11 小时

先修要求：具备 Python/Pandas 基础知识。

## 学习目标

- **Scikit-learn 核心 API**：理解并运用 Scikit-learn 库的主要组成部分，包括估算器、预测器和转换器。
- **数据准备**：使用 Scikit-learn 应用常见数据预处理技术，如特征缩放、类别特征编码和缺失值处理。
- **监督学习模型**：实现并评估用于回归和分类问题的常见监督学习算法。
- **模型评估**：选择合适的度量指标并使用交叉验证技术可靠地评估模型表现。
- **管道构建**：使用 Scikit-learn 管道构建和管理机器学习工作流程，以整合预处理和模型步骤。
