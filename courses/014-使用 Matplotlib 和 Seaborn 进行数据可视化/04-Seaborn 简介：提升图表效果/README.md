# 第 4 章：Seaborn 简介：提升图表效果

来源：[原章节](https://apxml.com/zh/courses/data-visualization-matplotlib-seaborn/chapter-4-seaborn-enhanced-visuals-intro)

[返回课程目录](../README.md)

在学会了 Matplotlib 绘图的基本操作后，本章将介绍 Seaborn。Seaborn 是一个基于 Matplotlib 构建的 Python 库，它提供了一个更高级的界面，用于创建有意义的统计图表。它通常能简化常见图表的代码，并提供美观的默认样式。

您将学习如何使用 Seaborn 的样式、上下文和丰富的调色板来控制图表的整体外观。我们将讲解如何使用 Seaborn 的专用函数创建散点图 (`scatterplot`) 和折线图 (`lineplot`) 等基本图表。此外，我们还将了解 Seaborn 如何与 Pandas DataFrame 良好配合，Pandas DataFrame 是一种常见的数据分析和可视化结构。本章重点在于使用 Seaborn 生成常用图表类型，以提升其美观度和统计表现力。
