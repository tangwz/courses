先修要求：基本 Python 知识有所帮助

## 学习目标

- **理解可视化原理**：认识数据可视化的重要性，并识别何时使用不同类型的图表。
- **使用 Matplotlib 制作基本图表**：使用 Matplotlib 生成折线图、散点图、条形图和直方图等基本图表。
- **自定义 Matplotlib 图表**：修改图表元素，如标题、标签、颜色、线条样式和坐标轴限制。
- **运用 Seaborn 制作优质图表**：运用 Seaborn 以更简洁的语法创建具有统计信息且美观的可视化图表。
- **数据分布与分类可视化**：使用 Seaborn 创建专门用于展示数据分布（直方图、核密度估计图、箱线图）和分类数据（条形图、计数图、簇状图）的图表。
- **与 Pandas 整合**：使用 Pandas DataFrame 加载数据，并直接使用 Matplotlib 和 Seaborn 从中制作可视化图表。
- **保存与分享可视化图表**：将图表保存为各种文件格式，用于报告、演示文稿或网页使用。
