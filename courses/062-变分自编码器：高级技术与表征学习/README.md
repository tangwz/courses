# 变分自编码器：高级技术与表征学习

来源：[变分自编码器：高级技术与表征学习](https://apxml.com/zh/courses/vae-representation-learning)

本课程详尽讲解变分自编码器 (VAE) 及其在表征学习中的应用。内容涵盖高级 VAE 架构、精密推断方法、旨在获得解耦表征以及它们在复杂数据类型上的扩展。本课程专为人工智能工程师和研究人员设计，侧重于前沿 VAE 模型的理论基础和实际实现。

预计学时：60 小时

先修要求：深度学习、数学、Python基础

## 学习目标

- **高级变分自编码器架构**：实现并批判性评估一系列高级变分自编码器架构，包括 CVAE、VQ-VAE 和分层 VAE。
- **精密推断方法**：应用并分析高级变分推断技术，如 IWAE 和结构化后验方法，以提升 VAE 性能。
- **解耦表征学习**：开发用于学习解耦表征的 VAE 模型，并使用既定指标和理论体系评估其质量。
- **变分自编码器的数学原理**：获得对支配变分自编码器的数学原理的透彻理解，包括 ELBO、重参数化和 KL 散度。
- **变分自编码器在复杂数据中的应用**：调整并实现变分自编码器，用于建模序列、结构化和高维数据，例如文本、图和图像。
- **混合生成模型**：分析并构建结合变分自编码器与其他生成技术的混合模型，如 VAE-GAN，以增强其能力。
