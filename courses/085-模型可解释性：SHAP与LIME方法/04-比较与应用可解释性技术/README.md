# 第 4 章：比较与应用可解释性技术

来源：[原章节](https://apxml.com/zh/courses/model-interpretability-explainability/chapter-4-comparing-applying-techniques)

[返回课程目录](../README.md)

您已分别了解了 LIME 和 SHAP 的工作原理。本章将这两种技术结合起来，提供一个比较视角，帮助您有效选择和应用它们。

我们将审视 LIME 和 SHAP 生成解释方式的主要不同之处，并讨论这些不同之处所带来的相对优势和劣势。您将获得实践指导，根据您的模型类型、数据特点以及具体的模型可解释性目标，选择最适合的技术。

此外，我们还将考察如何在常见的机器学习情境中应用这些方法，特别是针对回归和分类任务，并演示如何将解释生成整合到您的开发流程中。最后，我们将讨论在使用 LIME 和 SHAP 时可能遇到的常见考量和潜在难点。
