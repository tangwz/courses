# 高级机器学习系统中的因果推断

来源：[高级机器学习系统中的因果推断](https://apxml.com/zh/courses/causal-inference-ml-systems)

在机器学习 (machine learning)系统中应用复杂的因果推断技术。本课程涵盖因果关系的进阶识别方法、高维数据下的效应估计、处理未观测到的混淆因素，以及如何整合到机器学习流程中，旨在帮助寻求构建更可靠、可解释的人工智能系统的专家从业者。

预计学时：60 小时

先修要求：机器学习基础、因果推断知识、Python编程。

## 学习目标

- **因果关系的进阶识别**：应用和评估最先进的算法，以找出观测数据和干预数据中的因果结构。
- **高维效应估计**：应用如双重机器学习和因果森林等方法，在高复杂度数据集中估计异质性处理效应。
- **处理隐藏偏差**：使用如工具变量、RDD、DiD和近端推断等技术，以减少未观测到的混淆和选择偏差。
- **动态环境下的因果推断**：分析时间序列数据和动态处理方案中的因果关系。
- **系统整合**：将因果考量和方法直接整合到机器学习的开发、评估和监控流程中。
