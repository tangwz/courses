# 使用LangChain构建大型语言模型应用

来源：[使用LangChain构建大型语言模型应用](https://apxml.com/zh/courses/building-llm-apps-with-langchain)

本课程提供一个全面指南，教你如何使用LangChain框架构建大型语言模型应用。它介绍构建精巧、数据感知和智能代理系统所需的核心组成部分。你将学习如何组织提示词 (prompt)、串联模型、连接外部数据源以进行检索增强生成（RAG），以及创建能推理 (inference)和行动的自主代理。本课程内容从模型和提示词等基础知识开始，逐步到构建多步骤的复杂链和代理，助你开发出可投入实际使用的LLM应用。

预计学时：14 小时

先修要求：中级Python编程经验

## 学习目标

- **LangChain基础**：了解LangChain框架用于LLM应用开发的核心架构和组成部分。
- **提示词工程**：构建动态且有效的提示词模板，以指导大型语言模型输出完成各项任务。
- **链与顺序处理**：通过将大型语言模型及其他组成部分连接成顺序链，来构建和管理多步骤工作流程。
- **检索增强生成（RAG）**：将大型语言模型与外部数据源结合，使用文档加载器、向量存储和检索器来构建问答系统。
- **会话记忆**：通过添加不同类型的记忆来管理会话历史，从而实现有状态应用。
- **自主代理**：开发能使用工具与环境互动、做出决策并完成任务的代理。
- **应用监控**：使用LangSmith跟踪、调试和监控你的LangChain应用性能。
