# 深度学习中的模型正则化与优化

来源：[深度学习中的模型正则化与优化](https://apxml.com/zh/courses/deep-learning-regularization-optimization)

学习实用技术以防止深度学习 (deep learning)模型过拟合 (overfitting)，并提升其训练速度和表现。本课程涵盖L1/L2、Dropout和批量归一化 (normalization)等常见正则化 (regularization)方法，以及SGD、Momentum、RMSprop和Adam等标准优化算法。您将通过流行深度学习框架获得动手实践经验。

预计学时：15 小时

先修要求：Python基础与深度学习基础

## 学习目标

- **过拟合诊断**：通过学习曲线和验证指标，识别深度学习模型中的过拟合和欠拟合。
- **正则化方法**：理解并实现L1、L2、弹性网络正则化技术。
- **Dropout应用**：有效应用Dropout，以减少神经网络中的过拟合。
- **批量归一化**：实现批量归一化，以稳定并加速网络训练。
- **优化算法**：区分各种梯度下降优化算法（SGD、Momentum、RMSprop、Adam），并了解其工作原理。
- **超参数调优**：理解优化器、学习率和正则化超参数之间的关联。
- **实践应用**：在标准深度学习流程中通过常用框架实现正则化和优化技术。
