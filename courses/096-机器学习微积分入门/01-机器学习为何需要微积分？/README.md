# 第 1 章：机器学习为何需要微积分？

来源：[原章节](https://apxml.com/zh/courses/calculus-fundamentals-machine-learning/chapter-1-why-calculus-for-ml)

[返回课程目录](../README.md)

本章阐明了为什么微积分是理解和处理机器学习算法的有用工具。我们会从考察数学在机器学习中扮演的一般作用开始，然后转向微积分所需的基础知识。

你将学到：

*   **函数：** 它们是什么，如何表示输入和输出之间的关系（比如将数据特征映射到预测结果），以及如何使用图表来展现它们。我们将查看常见类型，例如线性函数，它们通常表示为 $y = mx + b$。
*   **极限：** 函数中趋近特定值的思想。这种思想构成了导数构建的理论基础。我们会培养对极限意义的直觉。
*   **与机器学习的联系：** 这些最初的思想如何与构建和理解机器学习模型相关联。

到本章结束时，你将理解微积分在机器学习中的必要性，并熟悉函数和极限的基本组成部分。
