# 第 1 章：简介：微积分在机器学习中为何重要

来源：[原章节](https://apxml.com/zh/courses/calculus-essentials-machine-learning/chapter-1-calculus-ml-introduction)

[返回课程目录](../README.md)

机器学习通常涉及为模型寻找最佳参数。这个过程通常依赖于基于微积分的优化方法。本章阐明了理解微积分对处理机器学习算法有何益处。

我们首先会考察机器学习模型如何被视为数学函数。接着，我们检查优化的核心思想：根据某个度量标准，找出使模型表现最佳的参数值。这其中的要点是衡量模型性能如何随着参数调整而变化。这正是导数发挥作用的地方。我们将介绍导数作为瞬时变化的量度。最后，我们将这些观点联系起来，以说明微积分如何为重要的机器学习算法提供数学依据。

本章包括：

*   将机器学习模型表示为数学函数。
*   机器学习中优化的基本思想。
*   导数如何衡量变化率并指导优化。
*   微积分作为理解机器学习算法的基本工具的作用。
