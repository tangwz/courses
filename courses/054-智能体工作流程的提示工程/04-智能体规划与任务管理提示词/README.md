# 第 4 章：智能体规划与任务管理提示词

来源：[原章节](https://apxml.com/zh/courses/prompt-engineering-agentic-workflows/chapter-4-prompts-agent-planning-task-management)

[返回课程目录](../README.md)

人工智能智能体若要有效执行多步操作并完成复杂目标，就必须能够规划其行动并管理任务。本章侧重于使这些智能体能力成为可能的提示词工程技术。您将学习设计提示词，用于目标明确和问题拆解，无论是分解成顺序步骤还是分层结构。我们将介绍在提示词中嵌入操作限制和用户偏好以引导智能体规划的方法。您还将审视迭代规划与重新规划的策略，使智能体能够适应新信息或意料之外的问题。此外，本章详细说明如何提示智能体评估其计划的可行性，并监督更广泛的任务执行过程。这些知识通过实践操作得到巩固，在此您将设计提示词以指导智能体创建一份详细的多步计划。
