# 智能体工作流程的提示工程

来源：[智能体工作流程的提示工程](https://apxml.com/zh/courses/prompt-engineering-agentic-workflows)

本课程提供关于提示工程的全面指引，着重于构建和管理能完成复杂、多阶段任务的人工智能智能体。您将学会如何构建提示，使智能体能够规划、使用工具、管理记忆并执行精巧的流程。课程内容涉及操控智能体行为和提升其在自动化系统表现的进阶方法。

预计学时：18 小时

先修要求：大语言模型原理，基础提示词使用。

## 学习目标

- **智能体系统设计**：理解人工智能智能体的架构和构成，以及提示工程如何影响其行为。
- **进阶提示技巧**：应用精巧的提示策略，用于多步骤推理、任务分解和智能体操控。
- **工具整合**：构建提示，使人工智能智能体能有效地选择、使用并与外部工具和API交互。
- **智能体规划与记忆**：编写提示以指引智能体规划过程，并管理其短期和长期记忆。
- **调试与优化**：制定测试、调试和完善提示的方法，以提升智能体工作流程的可靠性和表现。
