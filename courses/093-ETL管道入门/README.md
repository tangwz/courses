# ETL管道入门

来源：[ETL管道入门](https://apxml.com/zh/courses/intro-etl-pipelines)

本课程介绍ETL（抽取、转换、载入）处理的基本认识。您将学习数据如何为分析和应用而移动、清理和组织。内容包括数据抽取的主要方式、转换规则和载入技巧。

预计学时：8 小时

先修要求：计算机基本操作能力

## 学习目标

- **ETL定义**：定义ETL并说明其在数据处理中的作用。
- **抽取方法**：识别从不同来源抽取数据的不同方法。
- **转换技巧**：描述常见的数据转换操作，例如清理、验证和组织。
- **载入策略**：解释将数据载入目标系统的不同方法。
- **管线组成**：识别ETL管道的典型组成部分和工作流程。
- **简单管道设计**：概述设计简单ETL流程所包含的步骤。
