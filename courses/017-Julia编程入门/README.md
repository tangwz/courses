# Julia编程入门

来源：[Julia编程入门](https://apxml.com/zh/courses/getting-started-julia-programming)

本课程全面介绍Julia编程语言，专为Julia新手或编程初学者设计。您将学习Julia的基本语法、数据结构、程序控制、函数和包管理，培养您编写高效、可读代码的能力，以应用于科学计算、数据科学和人工智能。

预计学时：22 小时

先修要求：无需预备知识。

## 学习目标

- **Julia语法及核心结构**：理解并正确使用Julia的基本语法、关键词和编程结构。
- **程序运行**：编写并运行简单的Julia程序，使用REPL和脚本文件。
- **数据类型与集合**：有效处理Julia的内置数据类型以及数组、元组、字典等常见集合。
- **程序控制的实现**：使用条件语句、循环和程序控制修改器，实现程序逻辑。
- **函数模块化编程**：定义、调用和管理函数，创建模块化和可复用代码。
