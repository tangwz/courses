# 自动编码器与特征学习入门

来源：[自动编码器与特征学习入门](https://apxml.com/zh/courses/introduction-autoencoders-feature-learning)

本课程介绍自动编码器，这是一种用于无监督学习 (supervised learning) (unsupervised learning)的人工神经网络 (neural network)，及其在特征学习中的应用。您将学习自动编码器的基本结构，它们如何压缩和重构数据，以及它们在降维和数据表示中的作用。本课程结合实际案例讲解核心知识点，助您从零开始建立理解。

预计学时：14 小时

先修要求：Python基础知识

## 学习目标

- **自动编码器基本原理**：理解自动编码器的基本结构和用途。
- **编码与解码**：解释自动编码器中数据压缩（编码）和重构（解码）的步骤。
- **特征学习**：描述自动编码器如何用于从数据中学习有意义的表示（特征）。
- **降维**：掌握自动编码器如何执行降维。
- **基本实现**：使用常用机器学习库实现一个简单的自动编码器。
