# 归一化流简介

来源：[归一化流简介](https://apxml.com/zh/courses/intro-normalizing-flows)

本课程讲解生成模型中归一化 (normalization)流的运行机制。你将学习如何通过可逆变换，将简单的基础分布转化为复杂的概率分布。课程内容涵盖变量替换定理的数学原理、雅可比行列式，以及 RealNVP 和掩码自回归 (autoregressive)流等标准流模型的结构。通过 PyTorch 代码实现，你将构建并训练流模型，用于生成数据及进行精确的密度估计。

预计学时：8 小时

先修要求：微积分、概率论及 Python 基础

## 学习目标

- **数学基础**：应用变量替换定理和雅可比行列式计算精确的概率密度。
- **流模型架构**：动手实现耦合层、掩码自回归流和平面流等模型结构。
- **密度估计**：使用精确极大似然估计方法训练流模型。
- **生成式建模**：利用逆向过程从学习到的复杂概率分布中高效采样。
