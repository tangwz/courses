# 第 5 章：多智能体系统

来源：[原章节](https://apxml.com/zh/courses/agentic-llm-memory-architectures/chapter-5-multi-agent-systems)

[返回课程目录](../README.md)

在考察了单个LLM智能体的架构和运作，包括它们的推理、规划和记忆能力之后，我们现在将关注点转向由多个相互配合的智能体组成的系统。本章将介绍设计、构建和管理多个LLM智能体并行运作的环境所需的基本理念。

您将学习到多智能体系统（MAS）设计中特别适用于LLM的基本原理。我们将讨论建立智能体间通信协议、为协作解决问题组织互动（运用如特定职责或团队层级等模式），以及实行需要同步行动或共享资源管理的任务的协调机制等重要方面。我们还会考虑包含竞争性互动和协商的情况。最后，我们会提及开发这些可能很复杂的系统时的实际考量。
