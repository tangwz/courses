# 高级贝叶斯机器学习

来源：[高级贝叶斯机器学习](https://apxml.com/zh/courses/bayesian-machine-learning)

构建并运用精妙的贝叶斯模型以应对复杂的机器学习 (machine learning)任务。本课程涵盖高级推断方法，例如马尔可夫链蒙特卡洛（MCMC）和变分推断（VI）、概率图模型、高斯过程以及贝叶斯深度学习 (deep learning)。课程侧重理论知识与实际操作的结合，旨在帮助人工智能工程师将概率方法和不确定性量化 (quantization)纳入日常工作。

预计学时：55 小时

先修要求：扎实的机器学习、概率论、Python基础。

## 学习目标

- **高级推断方法实现**：实现并诊断复杂的MCMC算法（Metropolis-Hastings, Gibbs, HMC）和变分推断方法（CAVI, SVI）。
- **精妙贝叶斯建模**：构建、搭建并评估高级贝叶斯模型，包含高斯过程、概率图模型和贝叶斯神经网络。
- **不确定性量化**：运用贝叶斯方法准确表示和解释模型不确定性。
- **模型选择与比较**：应用高级技术比较贝叶斯模型并评估其性能。
- **可扩展贝叶斯方法**：理解并运用将贝叶斯推断扩展到大型数据集的方法。
