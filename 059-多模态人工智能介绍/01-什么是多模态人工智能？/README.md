# 第 1 章：什么是多模态人工智能？

来源：[原章节](https://apxml.com/zh/courses/intro-to-multimodal-ai/chapter-1-what-is-multimodal-ai)

[返回课程目录](../README.md)

本章介绍多模态人工智能的基本认识。我们首先简要回顾人工智能的核心原理，以建立一个共同的起点。

您将了解到：

*   人工智能系统处理的不同数据“模态”，如文本、图像和音频。
*   多模态人工智能的定义，以及它与专注于单一数据类型的系统有何不同。
*   人工智能系统结合来自多种来源的信息时获得的好处。
*   当前正在使用的多模态系统实例。
*   这些系统开发中面临的常见难点。
*   一个说明性的任务，例如为图像生成描述，以看出这些认识的应用。
*   一个在熟悉技术中识别数据模态的实际练习。

完成本章后，您将对多模态人工智能所包含的内容及其在处理多样化信息中的重要性有扎实的掌握。
