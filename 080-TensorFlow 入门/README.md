## 学习目标

- **TensorFlow 核心操作**：操作张量，执行数学运算，并理解自动微分。
- **Keras API 模型构建**：使用Keras中的Sequential和Functional API来构建模型。
- **模型训练与评估**：使用恰当的优化器和损失函数编译模型，通过fit()方法训练模型，并评估其性能。
- **数据输入管线**：使用tf.data API创建高效的数据加载管线。
- **模型保存**：保存和加载训练好的TensorFlow模型及权重。
- **TensorBoard 集成**：使用TensorBoard可视化训练指标和模型图。
