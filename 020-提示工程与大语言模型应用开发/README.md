# 提示工程与大语言模型应用开发

来源：[提示工程与大语言模型应用开发](https://apxml.com/zh/courses/prompt-engineering-llm-application-development)

学习编写高效提示词 (prompt)并构建由大语言模型 (LLM)驱动的应用的实用方法。本课程讲授提示词设计原理、进阶提示技巧、与大语言模型API的交互，以及如何使用常见框架将模型集成到实际应用中。掌握开发稳定且精密的AI驱动软件的能力。

预计学时：30 小时

先修要求：熟悉Python基础知识者优先。

## 学习目标

- **提示词设计**：编写有效提示词，以引导大语言模型行为并获得预期输出。
- **进阶提示技巧**：运用少样本提示、思维链和指令遵循等方法。
- **大语言模型API交互**：通过API调用和响应处理，将大语言模型集成到应用中。
- **大语言模型框架**：运用LangChain或LlamaIndex等框架，组织大语言模型应用的开发。
- **输出管理**：解析并验证大语言模型的输出，以确保应用稳定性。
- **基础RAG**：运用简单的检索增强生成模式，将大语言模型与外部数据连接。
