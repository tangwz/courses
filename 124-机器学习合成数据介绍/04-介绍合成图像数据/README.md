# 第 4 章：介绍合成图像数据

来源：[原章节](https://apxml.com/zh/courses/intro-synthetic-data-ml/chapter-4-intro-synthetic-image-data)

[返回课程目录](../README.md)

我们将重点从结构化表格数据转移到图像数据。合成图像能满足机器学习中的特定需求，尤其是在计算机视觉任务中，因为获取大量、多样且带标注的数据集可能具有挑战性。

本章介绍生成合成图像的基本原理。你将了解合成数据在此方面的价值，回顾像素和颜色表示方式（如 $RGB$）等图像的基本属性，并学习通过编程创建基本图像的方法，例如使用简单的几何形状或图案。此外，我们将涵盖噪声和基本增强作为合成技术的使用，并简要介绍简单场景的渲染。最后，我们会提及生成高度逼真合成视觉效果的相关挑战。
