先修要求：了解Python基础有助益。

## 学习目标

- **合成数据基本原理**：定义合成数据，并说明其在解决机器学习数据局限性方面的作用。
- **数据生成原理**：理解创建模仿真实数据特性的人工数据的基本原理。
- **简单生成技术**：运用基本方法生成合成数据，包括基于规则的系统和统计抽样。
- **表格数据合成**：学习专门用于生成合成结构化（表格）数据的技术。
- **图像数据合成入门**：理解创建合成图像数据的入门方法。
- **合成数据评估**：认识评估合成数据质量的重要性，并学习基本评估方法。
- **常用工具认知**：了解用于生成合成数据的常用软件包。
