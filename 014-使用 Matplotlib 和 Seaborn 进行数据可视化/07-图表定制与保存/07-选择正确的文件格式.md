# 选择正确的文件格式

来源：[原文](https://apxml.com/zh/courses/data-visualization-matplotlib-seaborn/chapter-7-customizing-saving-visualizations/plot-file-format-choice)

[返回章节目录](README.md) · [返回课程目录](../README.md)

在保存图表时，选择正确的文件格式是一个重要的考虑。Matplotlib 支持多种格式，其中最常见的选择主要分为两大类：栅格图和矢量图。理解它们之间的区别对于根据您的需求选择合适的格式很重要。

### 栅格图 vs. 矢量图

想象您正在创建一个图像。您可以通过两种方式来完成：

1. **栅格图：** 可以将其想象成网格上的数字颜料。图像由固定网格上的微小方块（称为像素）组成。每个像素都有特定的颜色。常见的栅格格式包括 PNG、JPEG（或 JPG）、GIF 和 TIFF。

   - **优点：** 能很好地表示照片等复杂图像。
   - **缺点：** 依赖分辨率。如果您将栅格图像放大过多，它会变得像素化或模糊，因为您只是在放大单个方块。文件大小可能很大，特别是对于高分辨率图像。
2. **矢量图：** 可以将其想象成一组指令或数学方程。它不存储像素，而是存储诸如“从 A 点到 B 点画一条蓝线”或“在此处画一个以此为半径的红色圆圈”之类的命令。常见的矢量格式包括 SVG 和 PDF（它们可以包含矢量和栅格元素）。

   - **优点：** 不依赖分辨率。您可以将矢量图无限放大或缩小，它将始终保持完美的清晰度，因为绘图指令会根据新尺寸重新计算。对于典型图表（线条、形状、文本），通常文件尺寸较小。文本保持可搜索和可选中状态（在 PDF、SVG 等格式中）。
   - **缺点：** 不适用于具有复杂像素色彩变化的写实图像。

对于使用 Matplotlib 和 Seaborn 创建的数据可视化图表（它们主要由线条、形状和文本组成），矢量格式通常提供显著的优势，尤其是在质量和可伸缩性方面。然而，栅格格式也有其用处。

### 常见绘图文件格式

让我们来看看保存图表时最相关的格式：

#### 栅格格式

- **PNG（便携式网络图形）：**

  - 使用*无损*压缩，这意味着保存文件时不会丢失任何数据。这能保留线条、文本和点位的清晰细节。
  - 支持透明度，如果您需要将图表叠加到其他内容上，这会很有用。
  - 通常，对于包含清晰线条和文本的图表，PNG 比 JPG 更受青睐。
  - **何时使用：** 清晰度非常重要的网页图形，带透明度的图表，需要保留质量的中间保存。栅格格式的良好默认选择。
  - 示例：`plt.savefig('my_analysis_plot.png')`
- **JPEG/JPG（联合图像专家组）：**

  - 使用*有损*压缩，这意味着为了获得更小的文件大小，会丢弃一些图像信息。压缩量（和数据损失）通常可以调整。
  - 非常适合具有平滑渐变和复杂颜色模式的照片。
  - 可能会在清晰的线条和文本周围引入可见的伪影（模糊、块状），尤其是在较高压缩级别下。
  - 不支持透明度。
  - **何时使用：** 当文件大小是重要考虑因素且线条/文本的完美清晰度不那么重要时。有时用于非常复杂的图表（例如，密集的散点图、热力图），在这种情况下，压缩的好处大于轻微的质量损失，或用于只接受 JPG 的环境。
  - 示例：`plt.savefig('overview_heatmap.jpg', quality=90)`（质量参数 (parameter)是 JPG 特有的）

#### 矢量格式

- **PDF（便携式文档格式）：**

  - 文档共享的通用标准。
  - 非常适合嵌入 (embedding)到报告、论文和演示文稿中，用于打印或高分辨率查看。
  - 完美保留矢量图形，确保无限缩放而不失真。文本保持可选和可搜索。
  - 广泛兼容不同的操作系统和设备。
  - **何时使用：** 学术论文、报告、演示文稿、印刷材料，需要精确缩放和高质量的场景。
  - 示例：`plt.savefig('report_figure_1.pdf')`
- **SVG（可伸缩矢量图形）：**

  - 一种专为网页设计的基于 XML 的矢量图像格式。
  - 在网页浏览器中完美缩放而不失真。
  - 可以使用 CSS 和 JavaScript 进行操作，以实现交互式网络可视化（尽管这超出了基本保存的范围）。
  - 文本保持可选。
  - 受现代网页浏览器和矢量图形编辑器支持。
  - **何时使用：** 需要响应式或可缩放的网页图形，嵌入到网页中，在矢量图形软件（如 Inkscape 或 Adobe Illustrator）中进行进一步编辑。
  - 示例：`plt.savefig('web_visualization.svg')`

### 如何选择：实用指南

以下是一个简单的决策指南：

- **用于网页：**

  - **SVG：** 可伸缩性和清晰度的最佳选择。现代浏览器能很好地处理它。
  - **PNG：** 如果 SVG 不合适，一个不错的替代方案，或者需要透明度且不严格要求矢量格式。如果清晰的线条/文本很重要，请使用此格式。
  - **JPG：** 仅当文件大小是重要考虑因素并且图表不严重依赖清晰的线条（例如，非常密集的散点图）时使用。
- **用于打印/文档/报告/演示文稿：**

  - **PDF：** 通常是最佳选择。它确保在任何打印尺寸下都具有完美质量，并且是通用可读的。
  - **PNG：** 如果需要栅格格式，可以使用，但要确保分辨率足以满足预期的打印尺寸（例如，在 `savefig` 中设置 `dpi=300` 或更高）。
- **用于进一步编辑：**

  - **SVG：** 如果您打算在矢量图形软件中编辑图表元素，这是理想选择。
  - **PDF：** 在许多图形程序中也同样可编辑，尽管 SVG 通常更适合以网页为中心的编辑。
- **图表的一般经验法则：** 如果可能，从矢量格式（PDF 或 SVG）开始，因为它们为典型图表提供了最佳质量和可伸缩性。如果需要栅格格式，则退回使用 PNG，优先于 JPG，以获得线条艺术和文本的清晰度。当文件大小是绝对主要考虑因素时，请谨慎使用 JPG。

通过选择合适的文件格式，您可以确保您精心制作的可视化图表得到有效呈现，并在任何使用场景中保持其质量。
