# 第 7 章：图表定制与保存

来源：[原章节](https://apxml.com/zh/courses/data-visualization-matplotlib-seaborn/chapter-7-customizing-saving-visualizations)

[返回课程目录](../README.md)

你已经学会了使用 Matplotlib 和 Seaborn 绘制各种图表。默认图表虽然功能可用，但常需要调整，以提高清晰度、有效表达特定信息，或满足展示要求。本章着重讲解如何优化图表外观，并为在编程环境之外使用做好准备。

你将学到如何直接在图表上添加解释性文本和标注。我们将介绍控制图例位置和样式的方法。此外，你将学习调整整个图形大小和管理布局的技巧，尤其是在处理多个子图时。我们还将简要介绍 Matplotlib 的面向对象接口，以便进行更精细的控制。最后，你将学到将图表保存为 PNG、JPG、PDF 和 SVG 等不同文件格式的实际操作步骤，这些格式适用于报告、演示文稿或网页使用，并理解不同格式类型之间的区别。
