# 机器学习应用中级Python编程

来源：[机器学习应用中级Python编程](https://apxml.com/zh/courses/intermediate-python-programming-ml)

本课程旨在提升您专为机器学习 (machine learning)应用打造的Python编程能力。在您Python基础知识之上，精通NumPy和Pandas等核心库，用于数据处理、分析和准备。学习使用Matplotlib和Seaborn进行高效的数据可视化方法，并了解如何为常见的机器学习流程构建和优化Python代码。获得为模型训练准备数据的实际经验。

预计学时：25 小时

先修要求：了解Python基本编程知识

## 学习目标

- **进阶Python技巧**：运用列表生成式、生成器、装饰器以及面向对象编程原则等中级Python特性，这些特性与数据科学相关。
- **使用NumPy进行数值计算**：使用NumPy完成高效的数组运算、索引、切片、广播和线性代数操作。
- **使用Pandas处理数据**：运用Pandas的Series和DataFrame进行数据集的载入、清洗、转换、分组和合并。
- **数据可视化**：使用Matplotlib和Seaborn制作具有信息量的静态图表，用于数据分析和交流。
- **机器学习数据准备**：实施常见的数据预处理步骤，例如特征缩放、分类数据编码和数据集拆分。
- **高效Python代码编写**：按照机器学习项目的最佳实践，编写更清晰、高效且易于维护的Python代码。
