# 第 5 章：Pandas 介绍

来源：[原章节](https://apxml.com/zh/courses/essential-numpy-pandas/chapter-5-introduction-to-pandas)

[返回课程目录](../README.md)

在 NumPy 为数值计算打下良好底子后，我们现在转向 Pandas，这是一个专门用于处理 Python 结构化数据的库。NumPy 数组在数值任务上功能强大，但数据分析常涉及带有标签、混合数据类型和缺失值的表格数据。Pandas 提供高性能、易于使用的数据结构和数据分析工具，专门应对这些情况。

本章将介绍 Pandas 的主要组成部分：
*   其基本数据结构：一维的 `Series` 和二维的 `DataFrame`。
*   从多种来源（包含 Python 列表、字典和 NumPy 数组）创建 `Series` 和 `DataFrame` 的方法。
*   检查 `DataFrame` 的重要技巧，使用 `head()`、`info()` 和 `describe()` 等函数了解其结构、内容和数据类型。

本章结束后，你将能够创建并查看 Pandas 中用于大多数数据处理任务的基本组成部分。一次实践练习将巩固这些知识。
