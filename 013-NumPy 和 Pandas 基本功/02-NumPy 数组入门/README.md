# 第 2 章：NumPy 数组入门

来源：[原章节](https://apxml.com/zh/courses/essential-numpy-pandas/chapter-2-getting-started-numpy-arrays)

[返回课程目录](../README.md)

Python 中的数值计算通常从 NumPy 开始。本章介绍 NumPy N维数组（即 `ndarray`），它是高效数组运算的核心对象。你将学习如何创建这些数组，既可以从标准 Python 列表创建，也可以使用专门的 NumPy 函数来生成具有特定属性的数组，例如填充零的数组或数字序列。

我们将介绍 NumPy 数组可以存储的不同数据类型，以及为什么指定正确类型（$dtype$）对于性能和内存使用很重要。你还将学习如何查看数组的基本属性，例如它的维数（`ndim`）、形状（`shape`）和元素总数（`size`）。学完本章后，你将能够熟练地创建和检查 NumPy 数组的基本属性，为后续的操作和计算任务做好准备。
