# 第 1 章：模型评估简介

来源：[原章节](https://apxml.com/zh/courses/basics-model-evaluation-metrics/chapter-1-introduction-model-evaluation)

[返回课程目录](../README.md)

本章介绍评估机器学习模型的重要做法。构建模型只是过程的一部分；在模型能可靠使用之前，确定其有效性同样重要。我们将探讨为何评估模型表现是机器学习工作流程中的一个基本步骤。

您将了解评估指标，即用于衡量模型进行预测或估计有效程度的量化工具。我们将区分本课程中讨论的两种主要监督学习问题：分类（即将数据点分配到预定义类别）和回归（即预测连续数值）。本章通过明确这些定义并概述标准评估过程来奠定基础。

在本章结束时，您将能够：

*   在评估背景下定义什么是机器学习模型。
*   说明评估模型表现的原因。
*   理解使用评估指标的目的。
*   区分分类和回归任务并举例说明。
*   概述模型评估过程中涉及的主要步骤。
