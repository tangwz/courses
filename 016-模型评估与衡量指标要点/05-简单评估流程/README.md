# 第 5 章：简单评估流程

来源：[原章节](https://apxml.com/zh/courses/basics-model-evaluation-metrics/chapter-5-basic-evaluation-workflow)

[返回课程目录](../README.md)

在了解了分类和回归的特定度量指标以及数据划分的理由后，我们现在将这些知识应用到实用的工作流程中。本章将详细说明评估机器学习模型的常规步骤。

你将学习如何构建评估流程，从为你的特定问题类型选择合适的度量指标开始，正确地将数据划分为训练和测试子集，使用你的模型对未见过/未观测过的测试数据生成预测，最后计算并理解所得的性能指标。这提供了一个结构化的方法来判断模型在新数据上的表现如何。我们还将说明在此过程中常遇到的错误。
