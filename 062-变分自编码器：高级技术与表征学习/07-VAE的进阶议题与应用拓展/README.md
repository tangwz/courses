# 第 7 章：VAE的进阶议题与应用拓展

来源：[原章节](https://apxml.com/zh/courses/vae-representation-learning/chapter-7-advanced-vae-topics-extensions)

[返回课程目录](../README.md)

在对变分自编码器（VAE）的核心原理、高级架构和精密推理方法有所了解后，本章将视野拓宽，以考查其拓展应用以及与其他机器学习方法的结合。

您将掌握以下技能：
*   在半监督学习场景中应用VAE。
*   运用VAE进行异常检测和分布外数据识别。
*   认识VAE与生成对抗网络（GAN）的比较优势与不足。
*   构建并剖析VAE-GAN和对抗性自编码器（AAE）等混合模型。
*   明确VAE在基于模型的强化学习中的作用。
*   学习去噪VAE等方法，以使模型不易受输入扰动影响，并提升特征学习能力。
*   审视专门用于VAE训练的高级优化策略。

本章还包含关于实现混合VAE-GAN模型的实践练习，让您能够应用这些拓展知识点。
