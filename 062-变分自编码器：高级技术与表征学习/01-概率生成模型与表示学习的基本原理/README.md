# 第 1 章：概率生成模型与表示学习的基本原理

来源：[原章节](https://apxml.com/zh/courses/vae-representation-learning/chapter-1-probabilistic-models-representation-foundations)

[返回课程目录](../README.md)

本章为我们学习变分自编码器奠定必要知识。我们将首先从高级角度审视概率生成模型，理解它们如何旨在捕捉数据底层分布。我们还将讲解表示学习的核心原理，侧重于数据如何转化为对后续任务更有用的形式。这些基本议题对理解复杂 VAE 的架构和运行方式很有帮助。

我们的学习将从概率模型的高级视角开始，然后进入潜在变量模型的理论与表述。你将掌握表示学习的核心原理以及评估表示质量的方法，包括既定度量标准。回顾标准自编码器将阐明它们在生成任务中的局限性，从而强调了对 VAE 等模型的需求。我们还将考量信息论在表示学习中的作用。完成本章将为你提供必要的背景知识，以便有效学习后续的 VAE 内容。
