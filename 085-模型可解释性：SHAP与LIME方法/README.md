## 学习目标

- **可解释性原理**：区分可解释性和可说明性，并理解它们对机器学习模型的必要性。
- **LIME实作**：应用LIME算法解释各种机器学习模型的单个预测。
- **SHAP实作**：使用SHAP框架及其不同的解释器，生成模型行为的局部和全局解释。
- **解释结果评估**：理解如何解读和比较LIME和SHAP生成的输出结果。
- **实践运用**：将可解释性方法整合到标准的机器学习工作流程中，使用Python库。
